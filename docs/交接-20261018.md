## 三、这一轮做完了什么

### 地形（P0）
- 高度 0~5 的**整数层**（无斜坡、平地严格为 0）
- 小山两种：缓坡（可跳）与峭壁（跳不上）；小山随机最高 5 层
- 跳跃：`STEP_JUMP=1.15 层`，视觉加高 1.9 倍，相机跟**地面**而不是脚底
- 渲染：每 16 格合并成一个 mesh，只画露出的侧面，台阶处才画描边

### 破坏（P1）
- 地形：按材质硬度 2/4/6 刀；裂纹、碎石、尘烟、打击音效
- 物件：树/枯树/围栏 2 刀、石头 3 刀、**断墙与房子 4 刀**
- 倒地动画：树/围栏/断墙会倒（断墙从中间断成两半分别倒）；房子直接碎
- 掉落：木材 / 石块 / 砖头，随机 0~3 阶
- **存库**：`terrain_damage` 表，只存和种子不同的格子；重启读回
- 自愈：20 分钟

### 地貌（P2）
- 荒野 / 冰原（雪白→蓝冰）/ 沼泽 / 城区废墟
- 冰面移速 ×1.45、加速极慢（刹不住）；沼泽 ×0.58
- 僵尸也受地貌影响
- 沼泽水洼（比地面低一层，四周有岸）、涟漪、踩水下沉

### 流体
- 静水：挖空一格时，四邻有水就灌进来（**没有模拟，零开销**）
- 地火：烫玩家、烫僵尸，都有飘字
- **存库**：`terrain_fluid` 表

### 六种武器（这一轮的重头）
| 武器 | 动作 | 机制 | 概率 |
|---|---|---|---|
| 单手剑 | 前刺两下（6 帧） | 连刺：第二段延后 0.18 秒 | 10%→50% |
| 斧 | 左右交替劈 + 双手握 | 溅射 2~13 个（按品阶） | 必定 |
| 锤 | 从上往下劈 | 旋击：转 5 圈打四周 4.4 米 | 10%→40% |
| 长棍 | 从上往下砸 | 横扫：前方 37° 内 4~10 米直线 + 击退 | 10%→55% |
| 弯刀 | 从上往下砍 | 连砍 1~8 刀，每刀 60%，每刀前进一步 | 20% |
| 匕首 | 双手各一把 | 一次攻击两段：左手投掷（最远 14 米）+ 右手近战 | 投掷 20%→80% |
| 长枪 | 前刺 | 挑飞 6 格，1.5 秒后落地砸范围伤害 | 8%→20%（round409 调整） |

### 其他
- 所有特效动画**广播同步**（连砍/长棍变大/转圈/暴击跳打）
- 所有伤害数字广播（别人打的、溅射的、延迟的都能看到）
- 自动战斗：独立按钮、安全区自动走出、连死 3 次暂停 20 秒、高阶掉落优先、自动跳台阶、水里会跳出
- 键位模式：点【键位】才能拖动三个按钮，再点【保存】存位置

## 四、⚠️ 下一轮必须先做的四件事

这四条是我最后核查出来的**没做完/做错**的，按优先级排：

### ① 斧：溅射没有打到玩家
`_aoe_players` 被加到了**横扫**分支上（还在），**溅射分支没有**。
- 位置：`server/world.py` 的 `_weapon_fx`，`elif nm == '溅射':` 分支末尾
- 加一句：`self._aoe_players(p, m.x, m.z, weapons.SPLASH_R, max(1, int(round(dv * fx['value']))))`

### ② 长棍：横扫打玩家的半径写错了
横扫分支里现在有一句 `_aoe_players(..., weapons.SPLASH_R, ...)`（1.5 米），
应该是横扫的**直线长度** `_d`，而且要按 37° 夹角筛。
- 参照横扫打怪那段（同一个分支里上面十几行）的判定写法

### ③ 匕首：投掷物打不到玩家
`_arrow_tick` 里只遍历 `self.mobs`，没有 `self.players`。
- 加一段：对玩家做同样的线段命中判定，命中则 `q.hp -= dv` + 发 `hurts`

### ④ 长枪：玩家不会被挑到空中
现在 PvP 里「挑飞」只给了一份额外伤害，**没有真正升空**。
- 需要：服务端发 `fx kind='launch_me'`，客户端接管 1.5 秒的模型高度（可参考怪的 `flyUntil`）
- 要考虑：升空期间能不能操作、落地是否有范围伤害

### ⑤ 眩晕对玩家（可选）
现在没有任何武器带眩晕了（锤子改成了旋击），但机制还在。
如果以后要用，需要客户端锁输入。

## 五、这一轮踩过的坑（值得记下来）

### 1. 「静默丢弃」出现了 5 次
字段/事件从服务端到屏幕要穿过好几层，**中间任何一层没有它，就是不显示、不报错**：
- 客户端 `wsApplyWorld` 的**显式字段清单**漏了 `hpm` / `mq` / `jy`
- 服务端的 `_pend` 只拷 `hurts`/`mhits`/`me`，`flee` 被丢
- 广播里带的作者是 `cid`，客户端用的是 `role_id` → 全部匹配不上

→ 对策：`tools/check_field_map.py`；事件走 `_fx_broadcast`；**统一入口**（`_report_hit`）

### 2. `__slots__` 加字段忘了同步 —— 踩了 4 次
`Mob` / `Player` 都有 `__slots__`，加字段必须同时改 `__slots__` 和 `__init__`。
漏了的表现是**每帧抛异常**，而 tick 有 try/except → **整个僵尸逻辑静默失效**（怪不动）。

### 3. 批量替换把代码写串
用「代码片段形状」做批量替换时，`{'splash': True}` 这种形状在多个分支里都有，
结果把 A 分支的代码加到了 B 分支上（就是上面①②的由来）。
→ 对策：改多分支逻辑时**逐个定位**，不要按形状批量替换。

### 4. 早退条件挡住了后面的逻辑
`if not self._later: return` 把排在后面的「投掷队列」永远挡住了 →
飞刀根本不发射。教训：**一个函数管两件事时，早退条件要同时看两个队列**。

### 5. 渲染前有个「统一纠正 Y」的循环
那是修「别人陷进山里」加的，每帧重算别人的 y。
**任何加在它之前的高度变化都会被抹掉**（暴击跳打就是这么丢的）。
→ 要加高度，**加到那个循环里**，不要加在动画阶段。

## 六、架构上的几条硬规矩

| 规矩 | 原因 |
|---|---|
| tick 线程不碰磁盘，只 `post_save` | `check_mkt_threads.py` 会拦 |
| 金币只有 `_gain_gold()` 能改 | 内存权威 + 序列号，防覆盖 |
| 地形是**纯函数**，两边各算一遍再比对 | `check_terrain_sync.py` |
| 只用 `+ − × ÷`、`Math.floor`、`Math.sqrt` | 跨语言 libm 有 1ulp 误差 |
| 玩家的位置/朝向归**客户端**，伤害归**服务端** | 所以控制类特效对玩家要发事件 |
| `web/core/` 里不许碰浏览器 API | `check_core_dom.py` |
