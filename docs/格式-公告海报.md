## 1. 怎么出一张新公告（3 步，不用改代码）

```bash
# ① 改内容（纯 JSON，中文直接写，允许 <b> 加粗）
notepad tools\poster_news.json

# ② 出图
node tools\poster_news.js

# ③ 结果（自动按标题命名）
docs\shots\更新公告.png        ← 2360 宽（2x），存档/发群高清版
docs\shots\更新公告-手机.jpg   ← 1080 宽（1x），手机看，约 300KB
```

`tools\poster_news.json` 字段：

```jsonc
{
  "title":    "更 新 公 告",          // 大标题（字间距会被自动拉开，写的时候可以带空格）
  "date":     "2026-10-18",           // 副标题第一段
  "headline": "武器机制全部上线",      // 副标题第二段（这一版最想让人看到的一句）
  "badge":    "刷新页面即可生效",      // 底部绿色小胶囊（可不填）
  "foot":     "数值口径 / 去哪看 …",   // 底部小字（允许 <br> 和 <b>）
  "items": [                          // 卡片，数量随便（12 张也行，2 列瀑布流自动排）
    {
      "tag": "战斗",                  // 分类标签，颜色自动（见下表）
      "t":   "八种武器的手感彻底分开了",  // 卡片标题（一句话，别超过 16 字）
      "b":   ["<b>匕首</b>：…", "…"]    // 要点，2~5 条最好
    }
  ]
}
```

**标签配色是自动的**（`tools/poster_lib.js` 的 `C.tag`）：
战斗/玩法=橙 · 掉落/优化=绿 · 成长/系统=蓝 · 背包=紫 · 装备=金 · 交易行=浅金 · 画面=青 · 修复=红 · 提示=灰 · 群=天蓝 · 其它=米
**要加新标签**：往 `C.tag` 里加一行 `标签: '#颜色'` 就行。

## 2. 规格（改样式前先读这里）

| 项 | 值 | 说明 |
|---|---|---|
| 画布宽 | **1180**（出图 2x = 2360） | 手机长图，微信/QQ 里直接看 |
| 底色 | `#14120d` + 顶部暖棕径向渐变 + 38px 像素网格 | 和游戏同一个调子 |
| 主色 | 金 `#ffd83d` | 标题、编号、要点里的重点 |
| 正文 | `#dfe8d4`；次要 `#8f9a84` | 和游戏 UI 同一套 |
| 强调绿 | `#8ee0a8` | 底部胶囊、要点前的小方块 |
| 大标题 | 56px / 字距 12 / 金色 + 黑投影 + 金光 | 固定写「更 新 公 告」这种带空格的形式 |
| 副标题 | 19px / 字距 2 / `#b9c2a8` | 「日期 · 亮点 · 共 N 项改动」自动拼 |
| 卡片 | `#252a22→#1a1d18` 半透明 + 2px `#ffffff16` 边 + 圆角 14 + 内高光 | |
| 卡片标题 | 20.5px / 800 | 白色偏暖 `#eef4e4` |
| 要点 | 13.5px / 行高 1.72 | 前面一个 6px 圆角小方块 |
| 排版 | **两列瀑布流**（`column-count:2`） | 卡片按内容自然高度 ✗ 不会因为长短不一空一大块 ✓ |
| 出图 | PNG 2x + JPG 1x | JPG 由 Chrome 直接出，不依赖 PIL |

## 3. 内容规矩（和用户的口味对齐）

1. **只讲玩家能感知的东西** ✗ 不出现代码层：不提"服务器/客户端"、不提轮次号、不提字段名、不提"某某模块"
2. **能写数字就写数字**（50% 连刺 / 14 米 / 10 金币 / 保留 30 天）✗ 别写"大幅提升"
3. **概率类必须标口径**：图上的百分比是**满品阶（12 阶）**的值，1 阶从最低值起步 → 这句固定放底部小字
4. **一条改动一张卡** ✗ 不要一张卡塞三件事 ✓ 标题写成"玩家能得到什么"
5. **卡片数量不设限**（12 张排过 ✓ 长图自动变高）
6. 修 bug 也要写成人话：不写"修复了 X 的 Y 索引越界"，写"掉落物不再埋在山里"

## 4. 复用到的其它脚本

| 脚本 | 干什么 |
|---|---|
| `tools/poster_lib.js` | ★ 共用库：`page()` 骨架 + `cards()` 编号卡片 + `make()` 出图（PNG+JPG）。**新海报都 require 它** |
| `tools/poster_news.js` | 公告：读 `tools/poster_news.json` → 出图 |
| `tools/poster_weapons.js` | 图鉴：读 `tools/_poster_data.json`（由 `tools/poster_weapons_data.py` 从 `server/weapons.py` 生成）→ 图标用**游戏自己的 3D 模型**离屏渲染 |
| `tools/poster_weapons_data.py` | 从服务器权威表取武器数值（攻速/射程/扇形/系数/机制文案），**不手抄** |

★ 加一种"带图标"的说明图时：照 `poster_weapons.js` 的结构（离屏 WebGL 渲染游戏模型 → dataURL 塞进 HTML），样式仍然用 `poster_lib.js` 的那一套。
