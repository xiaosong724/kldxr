# 主城对象化（v4.3）

> 状态：已完成
> 日期：2026-10-22

## 目标

把 `server/town.py` 里写死的 24 个旧建筑，迁移成 `town_objects` 里的对象记录，
让主城和新放置物件走同一套数据模型。

## 做法

### 1. 旧建筑登记为目录项

每个旧建筑生成一条目录：

```text
id        legacy_<k>       例：legacy_warehouse
name      <原名>（旧）
category  building
model_id  （空：表示由旧渲染器绘制）
price     0
enabled   1
```

### 2. 每个建筑写一条对象

```text
catalog_id   legacy_<k>
x / z        矩形中心
rot          0
collision    按 x0..x1 / z0..z1 算出 AABB
meta_json    { k, style, wall, accent, roof, sign, door, door_at, floors, legacy:1 }
```

### 3. 客户端区分新旧

`web/platform/place.js` 里：

- `catalog` 以 `legacy_` 开头 → **跳过**，交给原有渲染器；
- 其余 → 用新模型套件渲染；
- `PlaceMode.stats()` 返回 `{rendered, legacySkipped}` 便于自检。

### 4. 下发半径

主城 500×500，玩家出生点 (-130,143) 到建筑群（原点附近）约 190m。
对象下发半径从 90m 提高到 **260m**，覆盖整个主城。

## 验证结果

| 项目 | 结果 |
|---|---|
| 旧建筑对象数 | 24 |
| 客户端识别 legacy | 24 |
| legacy 重复渲染 | 0（全部跳过）|
| 新建筑放置 | 24 个对象（1 建筑 + 23 家具）|
| 新旧共存 | 正常，无冲突 |
| JS 报错 | 无 |
