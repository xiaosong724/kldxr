## 三、已知坑（别重复踩）

1. **玩家模型必须乘 `G.HERO_SCALE`（0.42）**，否则分身大 2.4 倍
2. 头顶 UI 要放进**反向缩放子组**（`1/HERO_SCALE`），否则跟着缩小
3. `skillfx` 里 `k==='clone'` 的消息**一律不能进通用特效队列**（否则会播那团大白云雾）
4. `_report_hit` 里怪的主键是 `m.mid`（不是 `m.id`）
5. `_skill_cast` 里 `radius` 必须在安全区判断**之前**算（否则 UnboundLocalError）
6. `net.py` 登录读库**不能在 `with db()` 里再套一层 `db()`**（死锁）
7. `world` 里加字段必须同步 `Player.__slots__`
