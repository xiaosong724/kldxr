# 新手小镇 v3 · 现代建筑与店铺细节提示词

> 用途：给场景生成/建模/外包/后续迭代提供统一描述。  
> 关键词：**现代城市小镇、真实生活感、可进入、可交互、编号可定位**。  
> 原则：不要因为是“小镇”就做成纯古风/日式木屋；小镇也可以是现代城市肌理。

---

## 0. 总风格

- 现代城市小镇：**最高 2 层**（不做高层塔楼）；平屋顶、女儿墙、玻璃、金属、木饰面、混凝土，借鉴参考图的材质与临街立面。
- 建筑不是“一个盒子”：必须有入口雨棚、门牌、玻璃分格、空调机位、雨水管、屋顶设备/花园、车库或院子。
- 所有营业建筑必须有：**门头、橱窗、店招、营业时间牌、门口地垫、垃圾桶/花箱/自行车位**。
- 室内必须有：**入口过渡、主功能设备、储物、照明、地面分区、墙面装饰**；不能只有一张床/一个柜台。
- 色彩：低饱和城市底色（灰、米、暖白、深绿、木色），店铺用一个强调色；夜景用暖光橱窗 + 冷光路灯。
- 比例：一层 2.35 m，门 2.3 m，窗台 0.9 m，招牌 0.5–1.2 m；家具按真实尺寸；二楼可走楼梯上去。
- 性能：能合并的静态盒体合并；同类 NPC 实例化；招牌用图集；室内小物件不单独发光。

## 1. 编号与地图

所有东西都要有**名字 + 编号**，地图和现场一致：

| 前缀 | 含义 | 示例 |
|---|---|---|
| B | 公共/功能建筑 | B01 仓库 |
| H | 住宅 | H01 云顶别墅 |
| S | 商店 | S01 超市 |
| R | 道路 | R01 北门大道 |
| T | 传送阵 | T01 中央广场 |
| V/Y/F | 住宅细类 | V01 别墅 / Y01 小院 / F01 小平楼 |

- 地图：全景俯视、道路名称、建筑编号、点击显示名称/坐标。
- 现场：门牌号、路口路牌、店铺门头；住宅门口有 V/Y/F 编号。
- 新建筑必须同时更新：`server/town.py` → `tools/gen_town_data.py` → 地图/门牌。

## 2. 住宅

### 2.1 别墅 V01–V04

**外形**
- 两层现代体块，平屋顶，深挑檐/女儿墙；
- 一层大面积落地玻璃 + 木饰面门廊；
- 二层退台或玻璃阳台，金属/玻璃栏板；
- 侧院：草坪、花坛、树、长椅、围栏、信箱、门牌；
- 车库：卷帘门、车位线、充电桩/工具墙、车库顶空调；
- 车道：混凝土/透水砖，接主路；夜间车道灯。

**一层**
- 玄关：鞋柜、换鞋凳、穿衣镜、挂钩、地垫。
- 客厅：L 型沙发、单人椅、茶几、地毯、电视墙/电视、书架、落地灯、绿植、窗帘。
- 餐厅：6 人长桌、6 椅、吊灯、餐边柜、花瓶。
- 开放厨房：岛台、4 个吧凳、冰箱、四眼灶、油烟机、烤箱、水槽、洗碗机、吊柜/地柜、调料架、垃圾桶。
- 客卫：马桶、洗手台、镜子、毛巾架、排风扇。
- 洗衣/储物：洗衣机、烘干机、清洁柜、吸尘器。
- 楼梯：踏步、扶手、玻璃栏板、楼梯下储物。

**二层**
- 主卧：双人床、两个床头柜、床头灯、衣柜、斗柜、穿衣镜、地毯、窗帘。
- 次卧：单人床/上下铺、书桌、椅、书架、衣柜。
- 书房：书桌、人体工学椅、书架、台灯、打印机/电脑。
- 主卫：浴缸、淋浴玻璃、双台盆、马桶、毛巾架、地暖/排风。
- 走廊：家庭照片墙、边柜、吸顶灯。

### 2.2 小院 Y01–Y04

- 一层现代平房，围合小院；
- 院子：菜地/花圃、晾衣杆、水缸、石桌凳、工具棚、自行车；
- 室内：玄关、客厅（双人沙发/电视）、餐厨（小餐桌、冰箱、灶台、水槽）、卧室（双人床/衣柜）、卫生间（马桶/淋浴/洗手台）、储物间。

### 2.3 小平楼 F01–F04

- 两层现代窄楼，临街；
- 一层：小客厅、餐厨、卫生间、洗衣区；
- 二层：两间卧室、书桌、衣柜、小阳台；
- 屋顶：水箱、太阳能、晾晒区；
- 入口：信箱、门牌、雨棚、自行车位。

## 3. 超市 S01

**门头**
- 大面积玻璃橱窗、自动门/双开门、绿色/暖白店招；
- 门口：购物车/篮、促销立牌、地垫、垃圾桶、雨伞架。

**店内**
- 收银区：收银台、传送带、扫码枪、POS 屏、钱箱、购物袋架、购物篮堆叠。
- 货架：3–5 排双面货架，分层价签；端架促销堆头。
- 冷藏：立式冷柜/岛式冰柜，玻璃门，冷白光。
- 生鲜：果蔬陈列台、喷雾/保鲜灯、秤。
- 日用品：洗护、纸品、清洁用品；文具/电池小挂件。
- 后仓：纸箱、托盘、液压车、货架、员工水杯/排班表。
- 其他：监控球机、灭火器、应急灯、广播音箱、购物车停放区。

## 4. 饭店 S04 / 居酒屋 S05

**前场**
- 迎宾台、候餐长椅、菜单架、等位号牌；
- 餐桌：4 人桌/2 人桌，椅子，桌号牌，餐具筒，纸巾，调料瓶；
- 卡座/包间：隔断、移门、衣帽架；
- 出餐口（pass）：不锈钢台面、保温灯、出餐铃、订单夹；
- 收银/外卖区：收银机、打包袋、外卖架。

**后厨**
- 四眼灶/六眼灶、炒锅、汤锅、蒸柜、炸炉、烤箱；
- 排烟罩、新风、灭火毯；
- 备餐台、砧板、刀具架、调料车；
- 冷藏/冷冻柜、制冰机、洗碗机、三槽水池；
- 干货架、米面油、垃圾桶、地漏；
- 员工更衣/洗手池、排班表。

**餐具/细节**
- 碗盘架、筷子筒、茶杯/水壶、酒瓶、菜单黑板；
- 厨房防滑垫、墙上挂钩、温度计。

## 8. 茶馆 S08 / 花店 S09 / 书店 / 邮局 / 旅店 / 澡堂

- 花店：工作台、花桶、花剪、包装纸、冷柜、吊花、门口花架。

- 旅店：前台、钥匙柜、行李架、沙发、楼梯、客房床/桌/衣柜/卫浴。
- 澡堂：鞋柜、前台、更衣柜、淋浴、浴池、蒸汽、防滑垫、吹风机。

## 9. 街道与户外细节

- 主路：双向车道、中线/边线、斑马线、路缘石、人行道、盲道、排水口、井盖。
- 支路：人行道、路灯、路牌、门牌、垃圾桶、消防栓。
- 商业街：停车位、自行车架、公交站、自动售货机、户外座椅、遮阳伞、花箱。
- 公园：步道、池塘、凉亭、长椅、花坛、草坪、儿童游乐、健身器材、路灯。
- 住宅区：院墙/绿篱、信箱、门牌、车道、车库、晾衣、垃圾桶、儿童车。
- 市集：摊位、条纹棚、货箱、价牌、灯笼串、地垫。
- 夜间：橱窗暖光、路灯冷光、招牌发光、地面光池；不要全场景过曝。

## 10. NPC

- 店员：统一围裙/工牌，站在柜台后或收银旁； idle 微动作。
- 厨师/传菜：厨师服/围裙，传菜员端盘；有从出餐口到桌位的路线。
- 路人：通勤/休闲装，沿道路行走，路口停留。
- 猫狗：低多边形，随机在公园/店门口活动；不做养成。
- 打工玩家：穿工作围裙，按岗位路线自动工作；其他玩家可见同一动画。

## 12. 验收清单

- [ ] 从街上看，建筑不是纯盒子：有门头、雨棚、玻璃、门牌、屋顶设备。
- [ ] 别墅有车库/院子/二楼/阳台/屋顶露台。
- [ ] 室内每个房间有明确功能家具，不是空房。
- [ ] 超市有收银/货架/冷柜/后仓；饭店有前场/出餐口/后厨设备。
- [ ] 地图能按 B/H/S/R/T 编号定位，名称与现场一致。
- [ ] 道路连通，主路/支路/人行道/路口完整。
- [ ] 每个街区有长椅/灯/垃圾桶/花箱等生活细节。
- [ ] 新增内容不突破 draw call/三角形预算。
