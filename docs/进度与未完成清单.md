## 2. ✅ 已完成（按系统）

### 2.1 基础架构
- 账号注册/登录、WebSocket、SQLite、存档线程、tick 30Hz、分层（core 不碰浏览器 / tick 不碰磁盘）
- 云端部署（systemd `xiuxian`、43.138.171.250:8899/8900）、管理页（刷怪/PVP/妖兽/魔气/QQ 播报开关，**都会存库，重启不丢**）
- 无限区块地形、末日美术（天光/雾/废墟物件）、PWA 离线

### 2.2 世界 / 地形
- 高度差（小山最高 **5 层**，随机）、只能跳 1 格、≥3 格摔伤（5 点，每格 +5）
- 四种地貌：荒野 / 冰原（1.45× 速度）/ 沼泽（0.58× + 积水）/ 城区废墟
- **可破坏**：3 格内砍（草泥 2 / 砖 4 / 石 6 下）、只能往下挖一层、裂纹进度
- **自愈**：破坏 20 分钟自动恢复（惰性计算，不跑定时器）
- 流体：水 + 地火（挖穿就灌一格；地火烫人，**僵尸也会被烧**）
- 树/断墙：砍倒有倒地动画；建筑、拾取、安全区（僵尸不进、不能拆、不能 PK）

### 2.3 僵尸
- 8 种职业（白领/医生/工人/学生/外卖/保安/程序员/健身教练，各有外观）
- 等级分布、数值二次式、追击/漫游/散开、医生治疗、咬人有前摇
- 僵尸认地形高度、会被地火/玩家机制打、死后掉经验与掉落

### 2.4 战斗
- **服务器权威**：伤害、命中、扇形、射程全在服务端算
- **8 种武器**，机制各不同（匕首投掷 / 剑连刺 / 刀连砍 / 棍横扫 / 枪挑飞 / 斧溅射 / 锤旋击 / 弓远程）
- 攻速→起手/间隔换算、12 品阶伤害封顶、暴击/抗暴/暴伤/闪避/命中/穿透/减伤
- PvP：双方开关、安全区禁斗、魔气、夺取经验与背包物品、冷却与上限

### 2.5 装备 / 掉落
- 武器 + 防具两栏，12 品阶（配色+挂饰区分），**词条系统**（随机词条、按品阶）
- **耐久度**（方案里写"不做"，后来用户要求做了）：耐久归零自动卸下、回背包、坏装备卖系统 10 金币
- 掉落：材料 + 8 种武器 + 防具，品阶幂律（低怪也能出高阶）、掉率公式、地上拾取（按地形高度显示）
- 装备/背包：一键整理（品阶优先）、单件上锁（重启不丢）、整页勾选批量卖

### 2.6 成长
- 等级（炼气 N 层，无上限）、经验公式、同级怪保底
- **天赋 11 项全部生效**（生命/攻击/减伤/移速/气/暴击/抗暴/暴伤/闪避/命中/穿透）+ 属性面板（基础/装备/天赋分离 + 上限）

### 2.7 社交 / 经济
- **组队**：5 人上限、邀请/申请/队长、经验分享（带 3%/15% 上限）、队伍频道（服务端）
- **交易所**：上架（含手续费）/ 购买 / 过期显示"已过期"可 30 天内取回 / 交易记录分页
- **QQ 群播报**：上线（带炼气层数）/ 突破 / 击杀 / 夺取 自动推到群（管理页可开关）

### 2.8 辅助功能
- 自动战斗（找怪 / 风筝 / 用弓自动远程 / 捡高品阶掉落 / 自己走出安全区 / 卡住绕行 / 换目标）
- 画面放大 80~200%（只放大 3D 画面）、攻击键大小、阴影/分辨率/锯齿/视野设置
- 百科（游戏内）、死亡复活、坠落音效、滚动播报、画面缩放的键位拖拽
