## 7. ★★ 今天踩过的坑（新会话必看 ✗ 否则会重踩）

### 改服务器代码

```
① ★ 按【端口】杀进程不可靠 ✗ 杀不掉 ✓
   → 表现：以为重启了 ✗ 其实旧进程还在跑 ✓ health 是旧进程答的 ✓
   → ★ 正解：按命令行匹配
     Get-CimInstance Win32_Process -Filter "Name='python.exe'" |
       Where-Object { $_.CommandLine -like '*app.py*' } | Stop-Process -Force
   → ★★ 判断重启成功必须看【进程启动时间 > 文件修改时间】✗ 不能只看 health ✓
     （今天就因此白折腾了一轮：金币一直不涨 ✗ 其实是旧进程 ✓）

② ★ 中文引号（""）放进 heredoc 里的 Python 字符串 → SyntaxError（至少 7 次）
   → 正解：注释全用 ASCII ✗ 或把脚本写成文件再跑 ✓
③ ★ heredoc 会吃掉 \n 和 \\ ✗ 转义用 \uXXXX ✓
④ ★ 用【文本匹配】改代码 ✗ 今天失败 6+ 次：
   · 中文引号 ✗ 尾部注释 ✗ 两个一模一样的循环（for (k in _marks) 有两处 ✗
     我插到了 if (!NET.on) 离线分支里 ✗ 正常玩永远不执行 ✓）
   · 删一行"冗余代码"时把它下面的续行留成孤儿 ✗ IndentationError ✓
   → ★ 正解：行号 + 整行原文/前缀双验证 ✗ ★★ 只插入 ✗ 不删行 ✓
     落盘前先 ast.parse ✓ 失败就 git checkout 回退 ✓
```
