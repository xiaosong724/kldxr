## 1. 一句话说清这个系统

**魔气 = 杀人杀出来的"凶名"** ✓。

```
好处：伤害更高（最多 +50%）· 抢别人经验/背包的概率更高（最多 15%）
坏处：你自己被杀时，会被【反夺取】—— 而且魔气越高，别人抢你越容易
     （机制上就是"谁魔气高谁抢谁"，魔气低的人反而抢不动你 ✓）
```

设计意图：它是一个**高风险高收益**的自愿 build ✓
不是"杀人越多越强"的单向奖励 ✗ —— 杀人多的人，也是别人眼里最肥的猎物 ✓

## 2. 魔气值的增减（用户原话 → 精确规则）

| 事件 | 变化 | 说明 |
|---|---|---|
| **击杀一名玩家** | **+2** | 只算 PVP 击杀 ✓ 打怪不算 ✗ |
| **被玩家击杀** | **−1** | 被怪打死不算 ✗（那是 PVE ✗） |
| **自然衰减** | **每小时 −1** | 见 §2.1（离线也算 ✓）|
| 下线 | 不额外扣 ✗ | 只按时间衰减 ✓ |
| 下限 | **0** | 不会变负 ✓ |

### 2.1 自然衰减怎么算（关键：不能"每小时跑一次定时器"✗）

```
★ 不做的方案：起一个"每小时给所有人 -1"的定时任务 ✗
   为什么不行：玩家离线时也要衰减 ✓ 而离线玩家不在内存里 ✗
   而且服务器可能重启 ✓ 定时器会丢 ✓

★ 采用的方案：记一个"上次结算时刻"✓ 用的时候现算 ✓
   角色表加两列：mq（魔气值）+ mq_at（上次结算的时间戳 ✓）
   任何时刻读魔气值：
       elapsed_hours = floor((now - mq_at) / 3600)
       mq = max(0, mq_raw - elapsed_hours)
       然后把 mq_at 往后推 elapsed_hours 小时 ✓（把已结算的时间"消费掉"✓）
   → 离线 10 小时回来 = 自动掉 10 点 ✓ 不用任何定时器 ✓
   → 服务器重启也不怕 ✓（时间戳在库里 ✓）
```

### 2.2 上限

```
魔气值上限 = 9999（防溢出 + 显示不至于撑破 ✓ 你想调说一声 ✓）
```

## 4. 魔气的收益

### 4.1 伤害加成（1 点 = +1%，上限 +50%）

| 魔气 | 伤害加成 |
|---|---|
| 0 | +0% |
| 10 | +10% |
| 25 | +25% |
| **50** | **+50% ← 封顶** |
| 100 / 200 / 500 | +50%（不再涨 ✓）|

```
★ 怎么叠加（要写清 ✗ 不然会和现有的三套加成打架）：
   最终伤害 = 基础伤害 × (1 + 魔气加成)
   其中基础伤害【已经含】固有攻击 + 武器 + 词条 + 天赋 ✓（现有的算法不动 ✓）
   ★ 魔气是【最后一个乘上去的】✗ 不再被别的加成放大 ✓
   ★ 现有的"至少吃 30% 伤害"地板【照样生效】✓ 魔气不会让谁变成无敌 ✓
   ★ 只在【PVP 伤害】上生效？还是打怪也生效？
     → 建议：打怪也生效 ✓（不然"魔气流"没法练级 ✓ 而且用户说的是"伤害"不是"PVP伤害"✓）
     → 这条要你确认 ✓ 见 §9 问题 ②
```

### 4.2 夺取概率（基础 5%，每 2 点 +0.2%，上限 15%）

| 魔气 | 概率 |
|---|---|
| 0 | 5.0% |
| 2 | 5.2% |
| 10 | 6.0% |
| 20 | 7.0% |
| 50 | 10.0% |
| **100** | **15.0% ← 封顶** |
| 200 / 500 | 15.0%（不再涨 ✓）|

```
公式： p = min(15.0, 5.0 + (魔气 / 2) × 0.2)
★ 魔气 100 正好到顶 ✓（(15-5)/0.2×2 = 100 ✓）很工整 ✓
```

### 4.3 夺取经验的比例（看**夺取方自己**的魔气）

| 夺取方魔气 | 夺走对方【当前经验】的 |
|---|---|
| 0 ~ 99 | **5%** |
| 100 ~ 199 | **8%** |
| 200 ~ 500 | **10%** |
| > 500 | **15%** |

```
★ 区间边界按你的原话：「没到 100」= [0,100) ✓「大于等于 100」✓
   「大于等于 200」✓「大于 500」✓ → 所以【500 整算 10% 档】✓
   要改成 [0,100)/[100,200)/[200,500)/[500,∞) 的话说一声 ✓
★ 底线保护（建议 ✓）：
   · 不会把对方夺到【掉级】✗（最多夺到当前等级的经验下限 ✓）
   · 不会夺成负数 ✓
   · 夺来的经验【直接进夺取方】✓ 并同时触发正常的升级检查 ✓
```

## 6. ★ 反夺取（这条最重要，也最容易做错）

### 6.1 用户原话怎么理解

> "魔气过高的缺点：被击杀后被反夺取的概率也相同，这个时候看谁的魔气高概率高，谁概率高用谁的"

```
我的理解（如果有偏差请纠正 ✗）：
   A 杀了 B → 本来该 A 夺 B ✓
   但同时算一下 B 的概率（B 也有魔气 ✓）
   · 如果【A 的概率更高】：按 A 的魔气算 → A 夺 B ✓（正常情况 ✓）
   · 如果【B 的概率更高】：★ 反过来了 ★ → B 反过来夺 A ✓
     也就是说：魔气高的人【去杀】一个魔气更高的人 ✗
                结果是自己被抢 ✓✓（这就是"魔气过高的缺点"✓）

   ★ 只掷一次骰子 ✓ 用【两边里更高的那个概率】✓
     不是"两边各掷一次"✗（那是两回事 ✓ 而且会变成双倍概率 ✗）
```

### 6.2 实例（照着做就不会错 ✓）

| 击杀方魔气 | 被击杀方魔气 | 谁的概率高 | 结果 |
|---|---|---|---|
| 10（6.0%）| 200（15.0%）| 被击杀方 | **被击杀方反夺击杀方**（15% 概率 ✓）|
| 200（15.0%）| 10（6.0%）| 击杀方 | 击杀方夺被击杀方（15% ✓）|
| 60（11.0%）| 60（11.0%）| 平手 | 按击杀方 ✓（进攻方优先 ✓ 建议 ✓）|
| 0（5.0%）| 0（5.0%）| 平手 | 按击杀方 ✓（就是"基础 5% 的普通夺取"✓）|
| 120（15.0%）| 100（15.0%）| 平手（都封顶）| 按击杀方 ✓ |

### 6.3 ★ 反夺取时，夺取比例看谁的魔气？

```
★ 我的建议：看【实际夺取方】自己的魔气 ✓
   · 击杀方夺 → 看击杀方的魔气（§4.3 的表 ✓）
   · 被击杀方反夺 → 看被击杀方的魔气 ✓（他魔气高 ✓ 所以夺得多 ✓ 这才叫"缺点"✓）
   → 这条要你确认 ✓ 见 §9 问题 ③
```

## 13. 一页总结

```
魔气 = 杀人杀出来的凶名

  物品 = 随机 1 件【没装备的】背包物品
  反夺取 = 谁概率高谁抢（平手算击杀方）

防刷：同一对 10 分钟一次 · 等级差 >20 不算 · 同账号不算 · 安全区不算 · 每天最多 +40
```
