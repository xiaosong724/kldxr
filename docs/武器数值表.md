## 一、伤害怎么算（回答"固定还是随等级涨"）

```
攻击力 = ( 固有攻击 × 武器系数 + 武器平伤 ) × 等级发挥度
           └────┬────┘   └──┬──┘    └────┬────┘
             随等级涨 ✓      固定 ✓       随等级涨 ✓

最后封顶：攻击力 ≤ 固有攻击 × 2.5        （装备最多贡献总伤害的 60%）

  固有攻击   = 10 + 3L + 0.08L²                    ← 只跟【玩家】等级走
  武器平伤   = 该阶基准值 × (1 + 0.06 × (物品等级-1))  ← 武器自带，固定
  等级发挥度 = 等级够 100%；不够则 40% ~ 100%        ← 跟等级差走
  建议等级   = 品阶 × 3 + 1
```

**结论：不是固定的 ✓** —— 同一把武器，玩家等级越高打出的伤害越高 ✓
但不是线性：

| 玩家等级 | 攻击力 | 每击 | 相对 1 级 |
|---|---|---|---|
| Lv.1 | 24.2 | 24 | 1.0 倍 |
| Lv.5 | 44.5 | 44 | 1.8 倍 |
| Lv.10 | 82.6 | 83 | 3.4 倍 |
| Lv.16 | 151.4 | 151 | 6.3 倍（发挥 100%）|
| Lv.20 | 185.9 | 186 | 7.7 倍 |
| Lv.30 | 288.8 | 289 | 12.0 倍 |
| Lv.50 | 565.2 | 565 | 23.4 倍 |

> 例：5 阶锤（系数 1.47、平伤 36、物品 1 级）
> **每击 = 攻击力取整**；暴击 ×1.5（20% 概率）；没有 ±10% 浮动 ✓

## 五、已知的两个数值问题（等决定）

### ① 封顶会把"低级拿高阶"的差距压平

```
1 级时：0 阶剑 16.1 · 4 阶斧 32.7 · 9 阶枪 32.7 · 11 阶锤 32.7
        → 4 阶以上全都一样 ✗ 低级捡到好东西没感觉 ✗
```

三个方向：**A** 不动（低级靠练级）· **B** 封顶放宽到 ×3.0（差异展开，但装备换代变慢）
· **C** 封顶跟等级走（1 级 ×2.5，每级 +0.05，50 级 ×5）

### ② 平伤不随攻速变化 → 高阶时快武器碾压慢武器

| 品阶 | 系数那一份 | 平伤那一份 | 平伤占比 |
|---|---|---|---|
| 0 | 13 | 3 | 19% |
| 4 | 63 | 24 | 28% |
| 8 | 135 | 104 | 44% |
| 11 | 204 | 290 | **59%** |

平伤占到 59% 时，它把系数那部分淹了 ✗
→ 12 阶时**匕首的每秒伤害比锤高 75%**（1416 vs 803）
→ 修法：**平伤也 ÷ S**（和系数一个待遇）→ 离散度 75% → 3% ✓
