# 皮肤自定义（捏脸 / 染色）· 方案 v1（round509，待确认）

> 用户："把五官和头发、衣服颜色改成自定义的；可更换：眼睛、嘴巴、头发颜色（有帽子就是帽子颜色）、衣服颜色；
> 换一个自定义的地方要消耗对应的一张皮肤卡片，可以预览，确认后再消耗，落库不丢；再补充完善。"

---

## 1. 一句话

**已经拥有的皮肤，可以花「重复的皮肤卡」改 4 个地方**：
👁 眼睛 → 👄 嘴巴 → 🎨 头发颜色（帽子皮肤 = 帽子颜色）→ 👕 衣服颜色

预览随便看 ✓ 点确认才扣卡 ✓ 扣了立刻落库 ✓ 换皮肤各自保存 ✓

---

## 2. 为什么是「重复的皮肤卡」

现在重复的卡只有一条出路：**卖系统 5000 金币**（或者挂交易所）。
把它变成「自定义材料」有三个好处：

| 好处 | 说明 |
|---|---|
| 重复卡突然有用了 | 玩家抽到重复不再只是"又一张 5000 块" |
| 天然防呆 | **只允许消耗【已经解锁过的皮肤】的卡** ✗ 绝不会吃掉你还没解锁的那张 ✓ |
| 不用新货币 | 不加"染料/颜料"这种新道具 ✓ 背包不用多一排 ✓ |

★ 但这条要你拍板：**"对应的一张皮肤卡"** 我理解成"任意一张（重复的）皮肤卡"，
如果你想要的是"改这套皮肤就得用这套皮肤的卡"，告诉我，改起来只是多一个校验。

---

## 3. 能改什么（4 + 1 项）

| 部位 | 选项 | 说明 |
|---|---|---|
| **眼睛** 👁 | 6 种眼型 | 男：窄长 / 方眼 / 上挑凶 / 小圆 / 眯眼（round508 那 5 个）+ 亮瞳<br>女：大眼 / 猫眼 / 垂眼 / 眯眼 / 圆眼 / 星眼 |
| **嘴巴** 👄 | 5 种嘴型 | 平静 / 微笑 / 抿嘴 / 张嘴 / 咧嘴（带一点牙）|
| **头发颜色** 🎨 | 18 色板 + 亮度 | **秃头/光头皮肤隐藏这一行**；`hood`（兜帽）/`veil`（头纱）显示成「帽子颜色」|
| **衣服颜色** 👕 | 18 色板 + 亮度 | 只改**主色**，副色/暗部/领口**自动按主色推**（`shirt`→`shirtD`/`shirtS`/`collar`），不会出现"上衣亮、下摆还是原色"的破图 |
| （加）**瞳色** 👀 | 12 色 | 和眼型分开，做成可选项 —— 眼睛已经选了形状，再给个颜色更好玩 |

★ **只改外观，不改任何属性** ✓ 攻击力/皮肤竞价/独占规则全都不受影响 ✓

## 4. 交互流程（预览 → 确认 → 扣卡 → 落库）

```
菜单 → 皮肤 → 选中一个【已拥有】的皮肤
   ↓
点「自定义」（右侧多一个按钮）
   ↓
┌──────────────────────────────┐
│  预览画布（实时变 ✗ 不扣卡）     │
│  [眼睛] [嘴巴] [头发/帽子] [衣服] │  ← 4 个分类切换
│  一排色块 / 一排样式小图          │
│  [按住看原样]  [随机一套]         │
│  ┌──────────────────────────┐  │
│  │ 这次要花：1 张皮肤卡        │  │
│  │ 你有：重复卡 3 张           │  │
│  │      [取消]   [确认更换]    │  │
│  └──────────────────────────┘  │
└──────────────────────────────┘
```

- **预览绝不扣卡** ✓ 关掉面板 = 什么都没发生 ✓
- **确认** = 走游戏内弹窗（`askConfirm`，不是系统弹窗 ✓ 和出价那个一样）
- 确认 → 服务器：**验卡 → 扣 1 张 → 写自定义 → 回执**
- 扣卡 + 写库在**同一个事务**里 ✗ 不会出现"卡扣了但颜色没存上" ✓
- 服务器是权威：客户端只说"我确认了，请写入这 4 个值"，**值合不合法服务器再验一遍** ✓

---

## 5. 存哪 / 怎么落库

**新表**（schema 13 → **14**）：

```sql
CREATE TABLE skin_custom (
  role_id  INTEGER NOT NULL,
  skin_key TEXT    NOT NULL,
  data     TEXT    NOT NULL,        -- {"ey":3,"mo":2,"hair":16437888,"shirt":3381504,"iris":3447003}
  at       INTEGER NOT NULL,
  PRIMARY KEY (role_id, skin_key)
);
```

- **按「皮肤」存** ✗ 不是按"角色"存 ✓ → 双马尾剑士染成粉色，巫女还是原色 ✓
- 每个皮肤只有**一套**自定义（不是衣柜 ✓ 想再改再花一张卡 ✓）
- 登录时随 `skinpage` 一起下发 ✓ 不额外请求 ✓
- 上线后**别人也能看到**你的颜色 ✓（快照加一个字段 `skc`，`check_field_map` 从 20 → **21** 字段 ✓）

## 6. 我补充的 8 条（你没提但会踩的坑）

| # | 补充 | 为什么 |
|---|---|---|
| 1 | **只允许消耗"已解锁皮肤"的重复卡** | 不然玩家会把还没解锁的卡当染料烧掉 ✗ 那是永久损失 ✓ |
| 2 | **背包里卡片要标出来**："重复（可当自定义材料）" / "未解锁（解锁用）" | 不标清楚就是坑 ✓ |
| 3 | **按住看原样** | 改了 4 个部位之后想对比原版 ✓ 不用来回点撤销 ✓ |
| 4 | **随机一套**（1 张卡）| 有人的乐趣就是"抽"✓ 也给不想纠结的人一个便宜选项 ✓ |
| 5 | **颜色做限制**：色板给 18 个"好看的"，自由滑条只允许 **亮度 ±**，不允许随便 hex | 随便调值一定会出现"荧光绿衣服 + 荧光青头发"✗ 满屏辣眼睛 ✓ |
| 6 | **秃头皮肤隐藏头发颜色行**；`hood`/`veil` 那两套显示成「帽子颜色」 | 现在 `veil`（头纱）的颜色是**写死的白色** ✗ 要改成跟 `hair` 走才染得动 ✓ |
| 7 | **独占/前三 不影响自定义** | 竞价管的是"谁能用这套皮肤" ✗ 染色是"用了之后长什么样" ✓ 两件事 ✓ |
| 8 | **管理页加两个按钮**：发 N 张卡 / 清空某人某皮肤的自定义 | 不然出问题只能手动改库 ✓ |

1. **耗卡规则**：任意重复卡（我推荐）／必须是该皮肤的卡？
2. **没卡怎么办**：只提示"去打怪/去交易所买"（我推荐）／允许 50000 金币替代？

| 3 | 👄 嘴巴 | 10 个 id | |

| 5 | 👕 衣服颜色 | 18 色板 + 亮度 | 副色/暗部/领口自动推 |

**「随机一套」不做** ✓

## 2. 数据契约（为了以后换美术不疼）

存的是**语义 key + 版本号**，不是数字下标：

```json
{"v":1, "ey":"narrow", "mo":"smile", "iris":3447003, "hair":16437888, "shirt":3381504}
```

- 为什么不用 `ey:3`：以后美术重做、删掉/合并某款眼睛时，数字会**指向另一个样子** ✗
  用 key 的话，服务器可以用一张映射表把老 key 迁到新 key ✓ 玩家不会"眼睛突然变样"
- 颜色存 **sRGB 整数**（`0xRRGGBB`）✗ 和现在 `SKIN_DEFS[k].c` 的格式完全一致 ✓
- 服务端持有**白名单**（合法 key + 颜色范围）✗ 客户端只发"我确认了" ✓

## 3. "以后优化美术"到底要多少工作量

先把现状说清楚：**这个项目的角色不是贴图模型，是程序化方块**
（`tools/skins_src/skin_hero.js` ≈ 700 行：`skBox` 拼骨架、`skHair/skOutfit/skAcc` 拼头发衣服、
`skEyeDraw/skMouth` 拼五官）。所以"改美术"分四种情况，代价差很多：

| 情况 | 要改什么 | 自定义系统要改吗 | 估时 |
|---|---|---|---|
| **A. 还是方块风，只调比例/配色/加零件**（最可能）| 改 `skin_hero.js` 的参数和颜色表 | **完全不用改** ✓（颜色走色板，眼睛走 key）| 1~2 天全量 |
| **B. 加新眼型/嘴型/发型/衣服** | 表情表 +1 行、衣服函数 +1 分支 | 只把新 key 加进白名单 ✓（UI 自动多一格）| 每款 0.5~2 小时 |
| **C. 换成贴图模型（GLB/图集）** | 渲染层重写、图集映射；`skBox` → `Mesh` | **协议不用改** ✓，但要把 key 映射到图集帧 | 3~5 天 |
| **D. 换成 2D 立绘/精细建模** | 基本等于重做角色管线 | 存储不用改，但 UI 的"10 款"要换成"选图" | 1 周以上 |

**结论**：只要保持"**存 key + 存颜色**"这条契约，
A/B 两种情况美术随便优化，**自定义系统一行都不用改** ✓
C 也只需改渲染层（存的东西一个字都不用动）✓
真正贵的只有 D（换整个角色管线）。

## 4. 顺带把"给美术留的接口"写进方案

1. 每款眼睛/嘴巴/颜色都有 **key**（`narrow` / `smile` / `#ffd83d`）✗ 不是裸数字 ✓
2. 皮肤定义里 `SKIN_DEFS[k].c` 的色板 key 固定（`hair/shirt/iris/...`）✗ 美术换色不改结构 ✓
3. `skBuildHero` 已经是"**数据进 → 模型出**"✗ 以后加 `def.eyes.v2` 之类也不影响老的 ✓
