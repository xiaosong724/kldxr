## 3. 住宅系统

### 3.1 数量与价格
- 别墅 4 套：**20 万/天**
- 小院 4 套：**10 万/天**
- 小平楼 4 套：**6 万/天**
- **每人最多 1 套**；
- 已有房不能买第二套，必须先主动退房或被买断。

### 3.2 购买/续期
- 新购 1~7 天；
- 续期最多延续到“当前时间起 7 天”；
- 到期未续自动待售，不退款；
- 门牌：`待售` / `某某的家 · 剩余 X 天`。

### 3.3 买断公式
```
剩余价值 = 剩余天数 × 当前日价
买断底价 = 剩余价值 × 1.5
溢价 = 买断价 - 剩余价值
```

原房主拿：
```
剩余天数 × 原房主实付日价
+ 溢价 × 10%
```
系统拿剩余部分。

**例子**：别墅 20 万/天，原房主买 3 天（60 万），过 1 天剩 2 天：
- 剩余价值 = 40 万
- 买断底价 = 60 万
- 溢价 = 20 万
- 原房主退款 = 40 万 + 2 万 = 42 万
- 系统收 18 万
- 新买家可再补最多 5 天，补的天按 20 万/天，不参与 10% 分成。

### 3.4 主动退房
- 房主可点「退房」；
- **剩余天数退 50%**；
- 房子立刻回到待售；
- 退房后可买其他房；
- 睡觉中先强制起床。

### 3.5 访问与睡觉
- **所有房子都可以进**，不锁门；
- **只有房主能使用床睡觉**；
- 非房主靠近床提示“这是某某的床”；
- 房主睡觉时被买断/到期：强制唤醒 + 传送到门口；
- 原房主离线且到期：下次登录若在屋内，传送到门口。

### 3.6 睡觉动画
- 走到床边 → 躺下 → 盖被子 → 闭眼；
- 镜头切到床侧；
- 每秒回 1% 生命/灵气；
- 其他玩家看到睡姿；
- 「起床」/移动/被买断 → 起床动画；
- 睡觉时不能打工、传送、购买、点菜。

### 3.7 数据
```
houses(id, tier, district, name, x,z, door_x,door_z,
       price_day, owner_id, owner_name, paid_day,
       started_at, expires_at, updated_at)
house_logs(id, house_id, buyer_id, seller_id,
           kind, days, amount, refund, premium, created_at)
```
- 每人 1 套：服务端校验 `owner_id` 唯一；
- 买断/续期/退款事务化；
- 离线退款进 `pending_gold`；
- 到期清理每分钟一次。

## 4. 打工/离线挂机

### 4.1 工位
- 普通店 1 个；
- 饭店、咖啡、超市、旅店：2~3 个（收银/后厨/传菜/理货）；
- 同一工位同一时间只能 1 人；
- 数据库唯一索引 `(shop_id, slot_id, active=1)`。

### 4.2 开始打工
- 店内「打工告示牌/经理 NPC」交互；
- 显示店名、工位、时薪、是否空闲、离线也计时；
- 确认后角色移动到工位；
- 原店员 NPC 隐藏，你的皮肤/名字出现在工位；
- 头顶显示「打工中」。

### 4.3 工作状态
- 只能在小镇内打工；
- 不能移动、攻击、跳跃、坐下、睡觉、传送、购买；
- **只能转动视角**；
- **不会死亡**：镇内安全区无伤害，工作状态额外无敌；
- 服务端异常把 HP 打到 0：强制退出打工并恢复，不播死亡；
- 角色自动执行营业任务动画：
  - 店员：柜台后擦桌、理货、招呼；
  - 传菜员：传菜口 → 端托盘 → 桌边 → 放下 → 返回；
  - 后厨：切菜、翻炒、装盘；
  - 清洁：扫地、擦窗；
- **玩家能看到自己在动**：第三人称镜头跟随，可旋转视角，角色沿预设路线自动移动；
- 其他玩家看到同一角色、同一动作、头顶「打工中」。

### 4.4 离线收益
- 退出游戏后工位保留，生成离线 NPC（你的皮肤/名字/打工中）；
- 每小时获得**当前等级升级所需经验的 3%**；
- 按小时循环，升级后下一小时按新等级算；
- 余下分钟存 `carry`；
- **离线收益上限 72 小时**；
- 上线后结算并提示；
- 服务器重启按时间戳补算；
- 在线连续打工不设 72 小时上限，只有离线结算封顶。

### 4.5 退出
- 在线点「退出打工」→ 结算 → 清除工位 → 回到工位前；
- 离线不能退出，必须上线点按钮；
- 打工中房子被买断/到期不影响打工；
- 退出后原店员 NPC 恢复。

### 4.6 数据
```
work_state(role_id, shop_id, slot_id,
           started_at, last_settle_at, carry_seconds, active)
work_routes(shop_id, slot_id, role, waypoints, anim_segments)
```
- 工位占用唯一；
- 同一人不能同时在两处打工；
- 离线 NPC 由 `work_state` + `work_routes` 生成；
- 上线时用玩家实体替换 NPC。

### 5.1 类型
- 店员：每家店柜台后 1 人；
- 传菜员：饭店/咖啡/奶茶/居酒屋/甜品店各 1 人；

### 5.2 行为

- 不做饥饿/口渴/抱起/投喂/宠物系统；

### 5.3 交互
- 店员：交谈 / 购买 / 点单；

- 路人：交谈，随机给提示；

### 5.4 性能

- 每个 NPC 用 `instanceColor` 区分衣服/头发/肤色；

### 8.1 落地（2026-10-22）：多对象弹窗选择

原方案只写了「多目标重叠 → ⋯ 展开；执行后中间提示立即关闭」，没写清怎么选、提示怎么显示。
按用户要求补成下面这套：

- **同时命中多个对象**（椅子 / 传送阵 / 床 / 房屋 / 冰箱 / 商店 / 仓库）时：

## 9. 性能架构

### 9.1 世界分块
- 地形：50×50 单位一块，10×10 块；
- 建筑/道具：25×25 单位一块，20×20 块；
- 只渲染镜头附近 3×3~5×5 块；
- 每块独立合并、独立视锥裁剪；
- 远处建筑 LOD（屋顶盒 + 立面片）。

### 9.2 合批/实例化
- 静态不透明：按块合并成 1 个顶点色网格；
- 自发光：按块合并成 1 个 Basic 网格；
- 透明：按透明度/贴图分组；
- 文字招牌：canvas atlas，1~2 次绘制；
- 树/路灯/箱子/花盆：InstancedMesh；
- NPC/猫狗：5~6 个 InstancedMesh。

### 9.3 NPC/动画
- AI 2Hz；
- 只更新 30 米内动画；
- 打工 NPC 用路线 + 开始时间确定性播放；
- 一次性动画走 `anim` 广播；
- 晚加入从快照恢复。

### 9.4 技能/VFX（借鉴 Linear）
- 线性技能：单 quad SDF 箭头；
- 范围技能：单 quad 圆环，边界按米；
- 技能阶段机：ARMED → TRAVEL → IMPACT → HOLD → FADE；
- 技能/粒子/地裂池化；
- 每个技能 2~6 draw calls，最多 4 个并发；
- 粒子按画质档位封顶（300/800/1500）；
- 服务器权威命中，客户端只表现；
- 镇外瞄准按地形高度采样。

### 9.5 预算
- draw calls ≤400；
- 三角形 ≤300k；
- geometries ≤300；
- textures ≤60；
- 桌面 60fps，手机 30fps；
- 每阶段用 `rd.info.render` 实测。
