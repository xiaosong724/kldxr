> 目标：开始实现前把所有设定、接点、冲突和验收标准写清楚，避免实现中反复改。
>
> 本文件是执行依据。实现时如果和本文件冲突，以本文件为准；确实需要改，先在文件末尾“变更记录”里写清楚再改。

## 0. 已确认规则

### 0.1 经验

- 精英怪、Boss 的经验按 **实际伤害贡献** 分配。
- 普通怪保持现状。
- 分身造成的伤害，贡献记给分身主人。

### 0.2 掉落

- 精英怪、Boss 的掉落按 **最后一刀** 归属。
- 最后一刀的人拿全部掉落。

### 0.3 存在范围

- 精英：玩家进入 **100 米**出现方向指示；100 米内有玩家时不消失。
- Boss：玩家进入 **1000 米**出现方向指示；1000 米内有玩家时不消失。

### 0.4 规模

- 精英：默认 3% 刷新率，同时最多 3 只。
- Boss：全服同时最多 1 只，20~40 分钟刷新一次。
- Boss 不进安全区。

### 0.5 定位

- 精英：2 个技能 + 1 个被动。
- Boss：3 个技能 + 二阶段。
- 普通怪不升级模型，保持现有性能。

## 1. 数据模型

### 1.1 Mob 新增字段

`server/mobs.py` 的 `Mob.__slots__` 追加：

```text
rank          0=普通 1=精英 2=Boss
skin          模型模板 id（字符串）
name          精英/Boss 显示名
hitR          大型怪额外命中半径（米）
dmgBy         {player_cid: 累计伤害}
dmgTotal      总伤害
markT         方向标记节流
castKey       当前技能 key
castPhase     windup / strike / recover
castT         当前阶段剩余时间
castX/castZ   技能落点
castYaw       技能朝向
skillCd       {skill_key: 冷却}
animState     idle / move / attack / cast / hit / death
animT         当前动画剩余时间
jumpT         暴击跳起剩余时间
bossPhase     1 / 2
```

`Mob.wire()` 只在末尾追加，**不能插中间**：

```text
现有 0~10 保持不变
11 rank
12 skin
```

动画状态、技能、暴击跳起不放进 30Hz 快照，走事件包，避免增加普通怪带宽。

### 1.2 精英/Boss 配置表

新增 `server/mob_ranks.py`：

```python
RANKS = {
  1: {
    'hp_mul': 3.5,
    'atk_mul': 1.8,
    'exp_mul': 4.0,
    'hit_r': 0.35,
    'affix_min': 2,
    'affix_max': 3,
    'control_mul': 0.5,
    'despawn_range': 100.0,
    'despawn_grace': 60.0,
    'max_alive': 3,
  },
  2: {
    'hp_mul': 12.0,
    'atk_mul': 2.5,
    'exp_mul': 15.0,
    'hit_r': 0.9,
    'affix_min': 4,
    'affix_max': 4,
    'control_mul': 0.0,
    'despawn_range': 1000.0,
    'despawn_grace': 300.0,
    'max_alive': 1,
  },
}
```

数值应用顺序固定，不允许在别处再乘一遍：

```text
普通怪：
  hp  = mob_hp(lv)  × 职业 hp 系数
  atk = mob_atk(lv) × 职业 atk 系数
  exp = mob_exp(lv)

精英/Boss：
  base_hp  = mob_hp(lv)          # 不套普通职业系数
  base_atk = mob_atk(lv)         # 不套普通职业系数
  hp  = round(base_hp  × rank.hp_mul)
  atk = base_atk × rank.atk_mul
  exp = round(mob_exp(lv) × rank.exp_mul)

最后再应用词条：
  hp  ×= (1 + hp_pct/100)
  atk ×= (1 + atk_pct/100)
```

`rank.hp_mul` 和 `rank.atk_mul` 只在 `Mob.__init__` 应用一次。


### 1.3 词条

新增 `server/mob_affixes.py`。

词条直接复用玩家词条语义，但不直接复用玩家数值：

```text
hp_pct        生命上限 +%
atk_pct       攻击 +%
crit_pt       暴击率 +%
crit_dmg      暴击伤害 +%
lifesteal     攻击吸血 %
thorns        反伤 %
dodge_pt      闪避 %
hit_pt        命中 %
pen_pt        穿透 %
dr_flat       固定减伤
dr_pct        百分比减伤
anticrit      免爆 %
anticritdmg   抗爆 %
speed         移速 %
aspd          攻速 %
burn          攻击附带灼烧
poison        攻击附带中毒
shield        开场护盾
regen         每秒回血
control_res   控制抵抗 %
```

数值公式：

```text
实际值 = 基础值 × (1 + 怪物等级 / 100)
```

上限：

- 精英：单条不超过基础值 2.5 倍
- Boss：单条不超过基础值 4 倍
- 暴击率总和不超过 40%
- 闪避总和不超过 30%
- 减伤总和不超过 60%

词条随机：

- 精英从池中抽 2~3 条，不重复
- Boss 抽 4 条，不重复
- 同一只怪不能同时出现互相冲突的词条（例如“纯护盾”和“纯闪避”可以共存，但同一属性不重复）

### 1.4 技能配置

新增 `server/boss_skills.py`：

```python
{
  'key': 'dragon_breath',
  'name': '骨龙息',
  'cd': 14.0,
  'range': 12.0,
  'min_range': 0.0,
  'cast_time': 1.8,
  'strike_at': 1.8,
  'recover': 0.8,
  'radius': 7.0,
  'cone': 70.0,
  'dmg_mul': 1.6,
  'hit_players': True,
  'hit_clones': True,
  'control': {'slow': 0.30, 'dur': 3.0},
  'telegraph': 'cone',
  'vfx': 'dragon_breath',
  'sfx': 'boss_breath',
}
```

所有 Boss 技能统一字段：

- `cd`：冷却
- `range` / `min_range`：释放距离
- `cast_time`：起手
- `strike_at`：服务器结算时间（通常等于 cast_time）
- `recover`：收招
- `radius` / `cone`
- `dmg_mul`：以 Boss 攻击力为基准
- `hit_players` / `hit_clones`
- `control`：附加控制
- `telegraph`：预警形状
- `vfx` / `sfx`
- `phase`：1 或 2（二阶段可用）

伤害上限：

```text
单次 Boss 技能伤害 ≤ 目标最大生命 × 45%
```

避免秒杀，避免装备差一点就完全没法玩。

## 2. 刷新 / 消失 / 数量

### 2.1 普通怪

完全保持现状：

- `MOB_VIEW = 100`
- `MOB_RENDER_CAP = 40`
- `AWAY_DIST = 20`
- 无玩家时清空普通怪

### 2.2 精英

- 每次普通刷怪时，3% 概率替换为精英。
- 精英等级 = 刷新点附近玩家等级 +1~3。
- 精英不占普通怪 `mob_cap`。
- 同时最多 3 只精英，超过不再触发。
- 出生位置：普通刷怪环 20~34 米，不能在安全区。
- 出生时广播附近 100 米：`mobspawn`。
- 100 米内有玩家 → `awayT = 0`，不消失。
- 100 米内无玩家连续 60 秒 → 移除。
- 精英死亡后 30 秒尸体淡出，不复活。

### 2.3 Boss

- 全服同时最多 1 只。
- `bossNextAt` 初始为当前时间 + 20~40 分钟随机。
- 时间到且当前无 Boss、且有玩家在线 → 刷新。
- 刷新点：
  - 随机选一名在线玩家
  - 在其 40~70 米外
  - 不能在安全区
  - 不能在水/岩浆/不可行走格
- 刷新时全服公告 + 方向标记。
- 1000 米内有玩家 → `awayT = 0`。
- 1000 米内无玩家连续 5 分钟 → 移除。
- Boss 死亡后重新计时 20~40 分钟。
- Boss 不参与普通怪 `mob_cap` / `MOB_RENDER_CAP` / `_evict_far`。
- 服务器重启后 Boss 不恢复，重新计时；这一点写进公告/交接，不假装持久化。

### 2.4 无玩家时

`_mob_tick` 现在无玩家会清空全部 `self.mobs`。改为：

- 普通怪：照旧清空
- 精英/Boss：保留，让 `awayT` 走完自己的宽限时间
- 如果没有普通怪也没有特殊怪，直接 return

这样不会出现“玩家刚下线 Boss 立刻消失”，也不会让特殊怪永久占内存。

## 3. 方向标记与模型加载

### 3.1 为什么不能只用现有快照

`_mobs_for` 只发 `MOB_VIEW = 100` 米内的怪，且最多 40 只。

Boss 要 1000 米方向，必须单独发标记。

### 3.2 新包 `mobmarks`

服务器每 1 秒发一次，只给范围内玩家：

```text
mobmarks {
  list: [
    { mid, rank, skin, name, x, z, hpPct, alive }
  ]
}
```

- 精英：玩家 100 米内
- Boss：玩家 1000 米内
- 只发精英/Boss，不发普通怪
- 死亡/离开范围后从列表移除
- 客户端维护 `NET.mobmarks`

### 3.3 客户端方向 HUD

- 精英：橙色菱形
- Boss：红色骷髅
- 在屏幕内：箭头/标记贴在目标头顶上方
- 在屏幕外：箭头贴屏幕边缘，指向目标
- 显示名字 + 距离
- Boss 优先于精英
- 同时最多 2 个精英 + 1 个 Boss
- 只对 `alive=1` 显示

### 3.4 模型加载

- 精英/Boss 进入 100 米才加载 3D 模型。
- 100~1000 米只有方向标记和 Boss 血条。
- 100 米外不播模型动画，只播必要的 Boss 技能音效/公告。
- 模型加载失败时保留方向标记，不阻塞游戏。

## 4. 战斗接入

### 4.1 玩家技能

现有技能已经遍历 `self.mobs`，不按普通怪过滤。必须逐项确认：

| 技能路径 | 处理 |
|---|---|
| 圆形 AOE | 命中精英/Boss |
| 直线地裂 | 命中，宽度按现有 |
| 扇形燃血斩 | 命中 |
| 延迟多段 | 命中 |
| 持续伤害 | 伤害贡献记施法者 |
| 箭矢/投射物 | 命中 |
| 黑洞吸力 | Boss 免疫拉拽；精英拉力减半 |
| 冰封 | Boss 免疫；精英时间减半 |
| 时间凝滞 | Boss 减速只吃 30%；精英 50% |
| 天罚/锤子眩晕 | Boss 免疫；精英 50% |
| 击退/挑飞 | Boss 免疫；精英 50% |

### 4.2 大型怪命中半径

现有近战判断是“玩家到怪物中心距离”。Boss 模型很大，会看起来“明明砍到了却打不中”。

新增：

```text
Mob.hitR
```

命中判定改为：

```text
有效距离 = 攻击距离 + m.hitR
```

- 普通：0
- 精英：0.35
- Boss：0.9
- 骨龙/巨蟒等特殊模型可单独覆盖。

客户端攻击指示/自动战斗距离也同步使用 `hitR`。

### 4.3 控制抵抗

新增统一函数：

```text
mob_control_mul(m, kind)
```

所有控制写入点都必须调用，不能只在技能入口判断。

需要检查的写入点：

- `m.stunT`
- `m.knockImmune` / 击退位移
- `m.freezeT`
- `m.slowT` / `m.slowMul`
- `_pulls` 拉拽
- 挑飞 `flyT`
- 天罚击倒

规则：

- 精英：控制时间 ×0.5
- Boss：控制时间 ×0
- Boss 仍然吃伤害，只是不被控制

### 4.3.1 PvE 属性对抗（必须做，不是自动生效）

结论先说：

- **玩家 vs 玩家**：现有 `talents.py` 已经有 `减伤↔穿透`、`闪避↔命中`、`暴击↔免爆`，PvP 代码里也已经生效。
- **玩家 vs 普通怪**：目前没有完整的怪物命中/闪避/减伤/穿透，玩家攻击怪物时也不会读取自己的命中/穿透。
- **玩家 vs 精英/Boss**：如果只给怪加词条、不接 PvE 结算，这些词条会变成“面板好看但没效果”。

所以精英/Boss 的属性必须走一套显式的 PvE 对抗，不能靠现有系统自动带出来。

#### 玩家攻击精英/Boss

按以下顺序结算：

```text
玩家命中 − 怪物闪避 → 是否闪避
玩家穿透 − 怪物减伤% → 有效减伤
怪物固定减伤 → 固定扣减
玩家暴击 − 怪物免爆 → 是否暴击
玩家暴伤 − 怪物抗爆 → 暴击倍率
最终伤害地板 30%
```

具体规则：

- 闪避只对 **普通攻击、单体投射物、单体技能** 生效
- AOE、持续伤害、地面技能默认不可闪避（避免一次技能十几个目标逐个 RNG）
- 命中高于怪物闪避时，不转化为额外伤害
- 怪物闪避上限 50%
- 穿透只削百分比减伤，不额外增伤
- 有效减伤最低 0，最终仍受 30% 伤害地板限制
- 被闪避的攻击不触发吸血、不触发被动、不记伤害贡献

#### 精英/Boss 攻击玩家

现有 `_mob_bite` 已经有玩家闪避、防具减伤、免爆。

需要补：

```text
怪物命中 − 玩家闪避 → 是否闪避
怪物穿透 − 玩家减伤% → 有效减伤
玩家固定减伤 → 固定扣减
怪物暴击 − 玩家免爆 → 是否暴击
怪物暴伤 − 玩家抗爆 → 暴击倍率
最终伤害地板 30%
```

- 普通攻击：可以闪避
- Boss 技能：默认不可闪避，只能靠减伤/护盾/走位
- 持续伤害：不可闪避，但吃减伤
- 玩家闪避上限 80%
- 怪物命中不转化为额外伤害

#### 怪物词条与玩家属性的对应

| 怪物词条 | 对抗的玩家属性 |
|---|---|
| 闪避 | 命中 |
| 减伤% | 穿透 |
| 固定减伤 | 固定减伤先扣，穿透不额外放大 |
| 免爆 | 暴击率 |
| 抗爆 | 暴击伤害 |
| 命中 | 闪避 |
| 穿透 | 减伤 |
| 暴击 | 免爆 |
| 暴击伤害 | 抗爆 |
| 吸血 | 无直接对抗，靠减伤/爆发 |
| 荆棘 | 无直接对抗，靠吸血/护盾 |

#### 统一结算入口

新增 `server/pve_combat.py`，只做三件事：

```text
player_hit_mob(p, m, raw, opts)
mob_hit_player(m, p, raw, opts)
mob_skill_hit(m, target, raw, opts)
```

所有玩家打怪、怪打玩家、Boss 技能都走这里，禁止在各个技能分支里再写一套减伤/闪避。

#### 显示

- 玩家闪避怪物攻击：飘 `闪避`
- 怪物闪避玩家攻击：飘 `闪避`，不弹伤害数字
- 玩家穿透生效：不额外飘字，避免刷屏
- 怪物减伤/免爆在精英/Boss 词条里可见

### 4.4 AI 分身

现状：

- `_mob_tick` 的 `live` 已经把分身加入目标
- `_mob_bite` 有 `_mob_bite_clone`
- `_clone_tick` 遍历所有 `self.mobs`

所以：

- 普通僵尸已经会咬分身
- 分身已经会打精英/Boss

需要补的只有：

- Boss 技能 AOE 命中分身
- Boss 技能伤害分身时，贡献记给分身主人
- Boss 二阶段召唤物也能攻击分身
- 分身死亡后，Boss 目标要重新选择

### 4.5 自动战斗

现状：

- `autoPickTarget` 遍历 `NET.rmobs`
- 没有按 rank 排除 Boss

需要补：

- Boss 进入自动战斗范围（30 米）时优先选 Boss
- 精英次优先
- 普通怪最后
- 不跨 1000 米追 Boss（方向标记只给手动）
- 目标死亡/消失后重新选
- 自动技能对 Boss 使用相同距离/命中半径判断

### 4.6 安全区

- Boss/精英不能进安全区。
- Boss 技能不伤害安全区内玩家。
- Boss 技能不伤害安全区分身。
- 玩家在安全区内不会被 Boss 选为目标。
- Boss 被拉进安全区 → 脱战、回原位、回血。

### 4.7 伤害贡献

`Mob.dmgBy` 记录：

```text
玩家直接伤害 → cid
玩家技能/持续伤害 → cid
分身伤害 → 分身主人的 cid
反伤/灼烧等间接伤害 → 实际来源 cid
```

每次扣怪物血都调用：

```text
_record_mob_damage(m, source_player, dmg)
```

必须覆盖的路径：

- `_skill_damage`
- `_line_skill`
- `_cone_skill`
- `_later_hits`
- `_earth_dot_tick`
- `_poison_tick`
- `_lava`
- 近战 `_intent_atk`
- 箭矢 `_arrow_tick`
- 分身攻击
- 任何新增 Boss 技能

### 4.8 经验分配

只对精英/Boss：

```text
总经验 = m.exp
个人贡献 = m.dmgBy[cid]
个人经验 = round(总经验 × 个人贡献 / 总伤害)
余数给伤害最高的人
```

规则：

- 每个贡献者独立结算
- 应用每个玩家自己的经验词条
- 不给队友额外 10%（避免重复分配）
- 没有贡献记录时，最后一刀拿全部
- 最后补一次余数，确保总和等于总经验
- 每个贡献者都要 `_save_role`
- 击杀计数/屠戮榜仍只记最后一刀

### 4.9 掉落

保持现状：

- `_roll_loot(killer, m)` 由最后一刀调用
- 精英/Boss 使用更高掉落表
- Boss 必掉至少一件高品阶
- 掉落归属不按贡献分

## 5. Boss / 精英技能

### 5.1 通用释放流程

```text
选目标
→ 判断距离/冷却
→ 进入 windup
→ 广播 mobskill phase=windup
→ 到 strike_at
→ 服务器结算伤害
→ 广播 mobskill phase=strike
→ recover
→ 回普通 AI
```

- 技能期间 Boss 不移动（冲锋类除外）。
- 技能阶段不能被普通攻击打断。
- Boss 技能冷却从 `strike` 后开始算。
- 客户端只播动画，伤害以服务器为准。

### 5.2 精英技能

#### 裂口者

- 被动：荆棘皮，近战反伤

- 被动：反伤甲，远程伤害减免

#### 火鬼

- 被动：灼烧，攻击附带持续伤害
- 技能 1：火焰喷吐，锥形灼烧
- 技能 2：爆燃，自身周围 AOE

#### 毒沼蟾

- 被动：毒皮，近战攻击者中毒
- 技能 1：毒液喷吐，落点毒池
- 技能 2：巨舌横扫，180° 横扫 + 击退

- 被动：刃甲，近战反伤 + 冲锋减伤

- 技能 1：影扑，跳跃扑击 + 减速
- 技能 2：群猎嚎叫，范围咆哮，强化附近小怪或削弱玩家

### 5.3 Boss 技能

#### 屠夫

1. 裂地重击：圆形预警，高伤害 + 击退
2. 钩锁：直线预警，拉人
3. 血腥旋风：自身周围多段伤害
4. 二阶段：攻速提高，旋风范围扩大，钩锁变为双钩

2. 暗影弹幕：扇形多发弹道
3. 召唤触手：召唤 2~4 只触手，有上限
4. 二阶段：弹幕数量增加，召唤触手 +2，获得一次短距瞬移

#### 钢铁巨兽

2. 冲锋：直线冲锋 + 眩晕
3. 核心过载：大范围蓄力爆发
4. 二阶段：炮击双发，冲锋留下灼烧路径，核心过载范围扩大

#### 骨龙

1. 骨龙息：正面锥形吐息 + 腐蚀
2. 骨翼风暴：360° 击退
3. 亡者召唤：召唤 3~5 只骷髅，Boss 死亡后清除
4. 二阶段：龙息范围扩大、召唤冷却缩短

#### 熔岩巨蟒

1. 熔岩喷发：落点连续喷发
2. 盘绞：近身环形绞杀 + 拉扯
3. 地火之池：留下 3~5 个熔岩池，持续 8 秒
4. 二阶段：移动留熔岩路径、火池数量增加

#### 虚空之眼

1. 虚空凝视：正面锥形光束 + 减速/沉默
2. 触手横扫：360° 多段触手拍击
3. 引力坍缩：大范围吸引 + 延迟爆炸
4. 二阶段：触手增加、坍缩范围扩大

## 6. 动画

### 6.1 动画状态机

所有精英/Boss 使用同一套语义状态：

```text
idle
move
attack
cast_windup
cast_strike
cast_recover
crit_jump
hurt
stun
freeze
death
```

服务器保存 `animState` + `animT`，客户端按状态播放。

### 6.2 服务器广播

`mobskill`：

```text
mobskill {
  mid, key, phase, x, z, yaw,
  name, radius, cast_time, strike_at, dur
}
```

`mobevt`：

```text
mobevt {
  mid, kind, x, z, yaw, t
}
```

`kind`：

- `crit`：暴击跳起
- `roar`：咆哮
- `phase2`：进入二阶段
- `death`：死亡动作

广播范围：

- 精英：100 米
- Boss：1000 米
- 但 100 米外只发轻量事件，客户端没有模型时只播声音/公告

### 6.2.1 技能名飘字

精英/Boss 每次进入 `mobskill phase='windup'` 时，头顶显示技能名。

规则：

- 只显示技能名，不显示“正在释放”之类废话
- 颜色按 rank：
  - 精英：橙色
  - Boss：红色
- 从头顶向上飘 0.8 米，1.2 秒淡出
- 不跟随伤害数字，不占血条位置
- 同一只怪同时只保留一个技能名，避免刷屏
- 技能名由服务器 `mobskill.name` 提供，客户端不能自己编
- 100 米内有模型：世界坐标头顶飘字
- Boss 在 100 米外、1000 米内：不显示世界飘字，改在屏幕顶部 Boss 血条下方显示一次
- 精英 100 米外没有模型，不显示
- `phase='strike'/'recover'` 不重复显示
- 死亡/被打断时立即清掉当前技能名

### 6.3 暴击跳起

- 只有服务器判定为暴击才发 `mobevt kind='crit'`
- 精英/Boss 都跳起/前扑
- 所有附近玩家同步
- 不暴击不发
- 伤害数字仍走 `mhits`，不重复

## 15. 边界与冲突决议（实现前锁定）

这一节专门处理实现时最容易反复改的地方。

### 15.1 目标选择

- 普通怪、精英、Boss 都使用现有 `live` 列表选最近目标。
- `live` 包含活着的玩家和 AI 分身；分身 cid 是 `clone:<id>`。
- 精英/Boss 的普通攻击可以打分身，沿用现有 `_mob_bite` / `_mob_bite_clone`。
- Boss 技能目标列表 = 玩家 + 分身；不包含 Boss 自己召唤的小怪。
- Boss 技能不会伤害自己的召唤物。
- 玩家死亡/复活动画不重置 Boss 仇恨；Boss 继续按最近目标行动。
- Boss 不因玩家进入安全区而丢失当前目标，但不会攻击安全区内目标；会重新选目标。

### 15.2 脱战与拴绳

- 精英出生点记录 `homeX/homeZ`；离出生点超过 50 米或进入安全区 → 回出生点，移动过程无敌/不攻击。
- Boss 出生点记录 `homeX/homeZ`；离出生点超过 80 米或进入安全区 → 回出生点，每秒回 5% 最大生命，回去后重新进入战斗。
- 精英/Boss 不跟随玩家跨半张地图；避免被风筝到安全区。
- 回程期间不触发技能、不进入二阶段。

### 15.3 二阶段

- Boss 血量首次 ≤50% 时进入二阶段，只触发一次。
- 即使之后回血超过 50%，也不回到一阶段。
- 二阶段改变技能参数/数量，不改变已损失血量。
- 二阶段触发广播 `mobevt kind='phase2'`，播放一次变身动画。
- Boss 死亡时清理二阶段召唤物。

### 15.4 召唤物

- Boss 召唤数量有上限：同时最多 6 只。
- 召唤物是普通怪，吃普通掉落/经验，不算 Boss 贡献。
- Boss 死亡时召唤物立即移除，不结算经验。
- 召唤物不占用 Boss 的“唯一”名额。
- 召唤物不会再次召唤。

### 15.5 玩家离线 / 贡献

- 伤害贡献按 `player_cid` 记录；分身记主人 cid。
- Boss/精英死亡时只给 **仍在线的贡献者** 分经验。
- 离线贡献者的份额不补给其他玩家，直接舍弃；总经验按在线贡献者重新归一化。
- 最后一刀玩家离线时，掉落落到地上，保留 60 秒。
- 如果没有任何在线贡献者，按最后一刀玩家结算；最后一刀也离线则不掉落、不结算经验。

### 15.6 队友 / PvP

- 精英/Boss 是 PvE 目标，不受 PvP 开关影响。
- 队友可以一起打，经验按各自伤害贡献分；**不再额外发 10% 队友经验**。
- 普通怪仍然保留现有队友 10% 经验。
- 安全区保护优先于一切 PvE 伤害。

### 15.7 死亡与尸体

- 精英/Boss 死亡后保留尸体 3 秒，播放死亡动画，再淡出。
- 死亡期间不再选目标、不释放技能、不阻挡移动。
- 尸体不参与方向标记。
- Boss 死亡后清除 Boss 血条和方向标记。
- Boss 死亡后重新开始 20~40 分钟计时。

### 15.8 地形与移动

- 精英/Boss 使用现有地形碰撞，不穿墙、不进岩浆。
- 毒沼蟾：短跳移动；跳跃不越过墙体。
- 刃甲虫：冲锋沿直线，撞墙提前结束并自晕 1 秒。
- 影狼：扑击不穿墙，落点被阻挡时改为原地扑击。
- 骨龙：地面行走/短低飞，不飞越不可行走区域。
- 熔岩巨蟒：盘踞型，移动慢；盘绞时定身。
- 虚空之眼：悬浮移动，贴地高度固定，不做飞行穿墙。
- 所有特殊怪仍走 `_move_mob` 的地形检查，不另写一套碰撞。

### 15.9 模型/动画失败兜底

- 模型构建失败时使用普通怪占位模型，不阻塞游戏。
- 动画状态缺失时回退 idle。
- Boss 技能 VFX 缺失时至少保留地面预警和时间结算。
- 方向标记不依赖模型加载。

### 15.10 带宽/性能

- `mobmarks` 1Hz，只发精英/Boss。
- 普通怪快照只多 `rank/skin` 两个字段。
- Boss 技能/暴击事件只在触发时发，不每帧发。
- 100 米外不创建 Boss 模型。
- 精英最多 3 只，Boss 1 只。
- 召唤物最多 6 只。
- 所有新 VFX 使用现有池/复用，不新建每帧对象。

### 15.11 刷新冲突

- 普通刷怪上限只统计 `rank=0`。
- 精英/Boss 不参与 `_evict_far`。
- 精英/Boss 不被普通怪 `MOB_RENDER_CAP` 挤掉。
- 精英/Boss 不占普通怪 `mob_cap`。
- Boss 刷新时如果已有 Boss，不再刷。
- 精英刷新时如果已有 3 只，不再替换。
- 刷新点不能落在安全区、岩浆、不可行走格。
- 如果找不到合法刷新点，本次不刷，下个周期再试。

### 15.12 服务重启

- 普通怪和精英/Boss 都不持久化。
- 服务器重启后 Boss 重新计时。
- 重启后的第一次刷新不会立即生成，仍等 20~40 分钟。
- 不恢复二阶段/召唤物/火池。

### 15.13 管理页

- 管理员刷出的 Boss 不改变正式 Boss 计时。
- 管理员清理只清理指定 rank。
- 管理页显示当前精英/Boss 数量、Boss 下次刷新时间。
- 普通玩家没有刷怪入口。

### 15.14 技能结算优先级

Boss 技能伤害依次经过：

```text
安全区检查
→ 无敌/复活保护
→ 护盾
→ 减伤
→ 伤害地板
→ 扣血
→ 死亡
```

和现有玩家受伤逻辑一致，不另开发一套。

### 15.15 经验总和校验

每次精英/Boss 死亡后打印一行：

```text
[mobexp] mid=... rank=... total=... shares={cid:exp} sum=...
```

测试时如果 `sum != total`，直接视为 bug，不允许上线。

## 16. v6 战斗规则调整（2026-10-21）

> 用户要求：精英/Boss 普通攻击全部近战；技能先锁定地点，读条结束后只伤害锁定区域内的目标；技能尽量做成可躲，难度只做高低差异。

### 17.1 普通攻击

- 精英/Boss：全部近战，必须追到接触距离。
- 普通程序员等普通远程怪：保留远程普通攻击。
- 普通远程攻击：
  - 无锁定圈
  - 发射可见弹丸
  - 弹丸飞向目标
  - 不进入精英/Boss 技能状态机

### 17.2 技能通用流程

```text
起手
→ 记录锁定地点（不是锁定玩家）
→ 锁定圈/读条
→ 读条结束
→ 用玩家当前坐标判断是否在锁定区域
→ 在区域内：伤害/控制
→ 在区域外：不结算
```

- 锁定后不追踪玩家。
- 读条期间不结算伤害。
- 玩家跑出去可以躲。
- 读条结束时跑回区域内，会重新被判定命中。

### 17.3 技能类型

| 类型 | 锁定/判定 |
|---|---|
| `aoe` | 锁定目标点，圆形 |
| `cone` | 施法者为原点，朝锁定点，扇形 |
| `line` | 施法者到锁定点的线段 |
| `self` | 以 Boss 自身为圆心，可跑出圈 |
| `zone` | 锁定点生成持续区域，离开后不吃后续 tick |
| `dash` | 锁定终点，读条后 Boss 冲刺，终点范围伤害 |
| `summon` | 召唤，不直接造成伤害 |

### 17.4 本轮特殊处理

- `summon`：
  - 深渊法师：召唤触手
  - 骨龙：亡者召唤
  - 不改成直接伤害技能。
- 地火之池：改为 `zone`，持续 6 秒，每 0.65 秒 tick。
- 冲锋/突进：保留 `dash`，锁定终点后冲刺。
- 自身范围爆发：锁定 Boss 自身，玩家可以跑出圈。
- 钩锁/盘绞/引力：命中后才拉拽/控制，跑出范围不拉。
- 扇形/直线：保持方向判定，可以侧移/绕后躲。

### 17.5 可躲难度

- 普通圆形 AoE：低~中，读条结束前离开。
- 扇形：中，侧移或绕后。
- 直线/钩锁：中，侧移出线段。
- 自身爆发：中，跑出 Boss 圈。
- 冲锋：中~高，先躲终点，再躲冲刺路径。
- 持续区域：高，进入后要尽快离开，不能站桩。
- 召唤：不直接命中，但会持续增加小怪压力。

### 17.6 技能表调整

- `kind='self'`：
  - 爆燃、振翅锯割、群猎嚎叫、血腥旋风、骨翼风暴、核心过载、触手横扫、盘绞
- `kind='dash'`：
  - 撕裂突进、甲壳冲锋、影扑、冲锋
- `kind='zone'`：
  - 地火之池
- 其余伤害技能保持 `aoe` / `cone` / `line`。
