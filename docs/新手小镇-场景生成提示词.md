# 新手小镇 · 场景生成提示词（v2）

> 用途：给场景/概念图生成器（或下一位接手的 AI）一份**和当前玩法完全对齐**的提示词。
> 数据源：`server/town.py` → `web/core/town_data.js`（建筑/道具/椅子/碰撞共用同一份）。
> 当前实现：24 栋可进入建筑、129 个街景道具、31 个可坐座位、289 个共享碰撞箱。

## 二、美术方向（给生成器的“眼”）

**一句话**：日式街角微缩模型 / 三渲二低模 / 暖黄昏 / 干净材质 / 清晰轮廓 / 灯火刚亮起来的商店街。

- **构图**：正交感的 3/4 俯视，中央是铺装广场与喷泉，四向主路把镇子切成街区；
  近景有屋顶、雨棚、灯笼串，中景是店面和招牌，远景是围墙、树带和钟楼尖顶。
- **体块**：建筑不是“盒子 + 平板屋顶”。每栋必须有：石基、木构架、窗、门、雨棚/招牌、
  坡屋顶（山墙朝街）、檐口、瓦垄、檐下斜撑。二层建筑要有阳台/外廊。
- **屋顶**：深青灰 / 赤茶 / 苔绿三种主色，山墙朝街；脊瓦、博风板、檐口、瓦垄、
  山墙通风窗、烟囱、水箱、天线按建筑功能出现。不要大面积空白屋顶。
- **材质**：奶油灰泥、深色木梁、灰瓦、青铜、旧砖、暖白玻璃、红漆鸟居、亚麻布。
  **不要**写实 PBR 贴图、不要脏污写实纹理；用低模色块 + 少量 canvas 文字招牌。
- **光**：低角度暖阳 + 冷灰天光；窗内暖光、灯笼、灯串、地面积水反光；
  商店门口有暖色光斑；广场喷泉偏青蓝。不要纯黑夜景，也不要正午惨白。
- **色彩比例**：60% 暖中性（米/木/石），25% 深青灰屋顶，15% 高饱和点缀
  （红灯笼、绿便利店、粉甜品、蓝布帘、樱花）。
- **生活感**：自动售货机、自行车、垃圾桶、木箱、酒桶、菜单立牌、邮筒、消防栓、
  公告板、公交站、晾衣杆、花盆、石灯笼、绘马、手推车、铁砧、煤堆、猫。
- **禁止**：镇内出现山体/陡坡/野怪；不要不可进入的“贴图房子”；不要悬空道具；
  不要没有碰撞的桌椅；不要用大片雾/黑遮住空场景；不要只有屋顶没有立面。

## 三、可直接粘贴的生成提示词

```text
生成一张 16:9 的游戏场景概念图：日式街角微缩模型（3D low-poly / 三渲二），
暖黄昏，干净、精致、可读性强的商店街小镇，3/4 俯视，略带正交感。

【范围与布局】
70×70 的方形小镇，四周有 1.75 米高的石基灰泥围墙，四边正中各开一个 7 米宽的门。
镇中心是 18×18 的浅色石板广场，中央一座圆形石喷泉（青色水面、铜色水柱）。
南北、东西两条 7 米宽的主路在广场交汇；主路画浅色虚线、斑马线、井盖和排水口。
广场四角各一棵树（两棵樱花、两棵绿树），树下有方形花坛和长椅；
广场上还有信息亭、小吃车、市集摊、邮筒、自行车架、灯串和石灯。

【建筑】
24 栋低模建筑，全部有门、窗、室内、可进入；不要做成一排同样的盒子。
北侧：新手大厅（两层、钟楼、圆窗、门廊、石阶、两侧长椅）、药铺、邮局、
旅店（两层、木阳台、红灯笼）、神社（鸟居、石灯笼、绘马架、注连绳）。
西侧：便利店（整面玻璃、绿色条带）、面包店（暖窗、面包陈列）、
咖啡店（红白雨棚、露台桌伞）、花店（花桶、吊花）。
东侧：面馆（红灯笼、暖帘、吧台凳、蒸汽）、甜品店（粉白雨棚）、杂货铺（木箱、货架）、
澡堂（蓝布帘、木格栅、烟囱）。
南侧：三栋民居（小院、木栅栏、晾衣杆、盆栽）、两层公寓（外廊、信箱、蓝栏杆）。
东南：大仓库（装卸雨棚、木箱、手推车、蓝灰铁皮）、铁匠铺（炉火、铁砧、煤堆、烟囱）。
每栋建筑：石基 + 木构架 + 奶油灰泥墙 + 深色窗框 + 暖光玻璃；
屋顶必须是坡屋顶，山墙朝向街道，带脊瓦、瓦垄、檐口、博风板和檐下斜撑；
允许出现烟囱、水箱、天线、山墙通风窗；不要大面积空白屋顶。
屋顶主色在深青灰、赤茶、苔绿之间变化，不要全部同色。

【街道与小物】
沿街布置：自动售货机（绿/红/蓝发光面板）、自行车、垃圾桶、木箱、酒桶、
菜单立牌、邮筒、消防栓、公告板、公交站（玻璃棚 + 长椅）、石灯笼、绘马架、
手推车、铁砧、煤堆、花盆、木栅栏、绿篱、晾衣杆、猫。
街道上方有细电线与暖色灯串；店门口有暖光地斑；广场喷泉边有长椅和花坛。
所有道具都要“落地”，有接触阴影，不要悬空。

【材质与光】
低模色块材质，不要写实 PBR 贴图；奶油灰泥、深色木梁、灰瓦、旧砖、青铜、
暖白玻璃、红漆、亚麻布。低角度暖阳从西南来，冷灰天光补暗部；
窗内暖光、灯笼、灯串、地面积水反光；广场喷泉偏青蓝。
整体是“黄昏刚亮灯”的氛围，不是纯黑夜，也不是正午惨白。

【构图】
近景：屋顶、雨棚、灯笼串；中景：店面、招牌、街道；远景：围墙、树带、钟楼尖顶。
画面要有前景/中景/远景三层，街道不要空，广场不要只剩空地。
招牌文字用简洁的日文/中文店招（便利店、拉面、CAFE、居酒屋、药、邮、汤、宿），
字体干净，不要乱码。

【禁止】
不要山体、陡坡、野怪、战斗特效；不要不可进入的贴图房子；
不要没有碰撞的桌椅；不要大片黑雾遮住空场景；不要所有建筑同一高度/同一屋顶；
不要写实脏污纹理；不要 UI、按钮、水印、人物大头像。
```

## 四、如果生成的是“可玩场景”而不是概念图

追加这段，把交互/碰撞一起生成：

```text
这是一个可玩的 Three.js 低模场景，不只是概念图。请保证：
1) 每栋建筑都有 2.3 米宽的门洞和可进入的室内，屋顶在玩家进入建筑足迹后隐藏；
2) 建筑墙体、外围墙、喷泉、仓库柜台、全部街景道具、全部椅子都有 AABB 碰撞；
3) 椅子是真实家具：有椅面/靠背/四腿，靠近 1.9 米内交互按钮变“坐下”，
   坐下后角色腿向前收、手放大腿、武器收起；按钮变“起身”，移动/按 E 起身；
4) 仓库柜台在 (13.1, 17)，靠近 2.8 米可打开 90 格仓库，支持批量存取；
5) 镇内每秒回复 1% 最大生命，镇内不刷怪、不能攻击；
6) 静态几何按材质合并，目标 ≤400 draw calls、≤200k 三角形、桌面 60fps。
```

## 五、验收清单

- [ ] 24 栋建筑的门都能走进去（门中心 `blocked=false`）
- [ ] 每栋建筑至少 2 个窗、1 个门、1 个招牌/雨棚、完整坡屋顶
- [ ] 31 个座位都能靠近、坐下、起身；椅子有碰撞箱
- [ ] 仓库柜台可打开、单件/批量存取
- [ ] 镇内地形平坦，无山体；镇内不刷怪
- [ ] 广场、主路、四门、围墙位置与上表一致
- [ ] 截图里没有大面积空白墙/空白屋顶；街道有前景/中景/远景
- [ ] 桌面端 ≥50fps，draw calls ≤400

## 六、当前实现备注

- 场景代码：`web/core/town.js`；布局唯一数据源：`server/town.py`；
  导出脚本：`tools/gen_town_data.py`；布局体检：`tools/test_town_layout.py`。
- 椅子协议：客户端 `sit` / 服务端 `seated`；起身 `stand` / `stood`；
  服务端校验距离、是否在同一间屋内；坐下位置由服务端吸附。
- 静态几何合并：不透明 1 次、自发光 1 次、透明按参数分组、文字招牌独立；
  屋顶每组单独合并，保证“进屋隐藏屋顶”仍然可用。
