## 1. 一句话说清

**自动战斗 = 客户端自己"假装有个玩家在操作"** ✓
它做的每一件事（往哪走、什么时候挥刀）都是一个真人能做出来的 ✓
所以**服务器一行都不用改** ✓

```
打开后：自动找最近的僵尸 → 走过去 → 到射程内就砍 → 捡东西 → 继续找下一只
关掉后：立刻停手，交回给你手动控制
```

## 2. ★ 为什么放在客户端做（这条要先说清楚）

```
这个项目的规矩：
  · 位置：客户端是权威的 ✓（服务器采信客户端报的坐标）
  · 伤害/掉落/死亡：服务器是权威的 ✓（服务器自己算扇形命中）

如果放在服务器端做 ✗：
  服务器一边推着你走 ✓ 客户端一边报自己的位置 ✗ → 两边打架 ✓
  （这个架构下服务器没有"移动玩家"的能力 ✓ 硬做会很难看 ✓）

放在客户端做 ✓：
  它只做两件事：改自己的位置（本来就归客户端 ✓）+ 发 atk 意图（和真人一样 ✓）
  → 服务器完全看不出来差别 ✓ 也不需要任何新协议 ✓
★ 代价（如实说）：客户端能做出来的事，理论上外挂也能做 ✗
  但试玩阶段无所谓 ✓ 而且这套本来也没防外挂 ✓
```

## 3. 它每一帧做什么（核心逻辑）

```
① 没目标 → 在【自身 R 米内】找最近的活僵尸
     · 跳过已死的（hp<=0 的还在播倒地动画 ✓ 不算）
     · 跳过【安全区内】的（安全区里僵尸进不来 ✓ 但边界上可能有 ✓ 一起跳过更稳）
     · 池子里没有 → 原地待机（不乱跑 ✓）

② 有目标 → 判断距离
     · 距离 > 射程×0.85 → 朝它走（和摇杆走的是【同一套移动代码】✓ 速度一样 ✓）
     · 距离 ≤ 射程×0.85 → 停下，转向它，冷却好了就挥刀（和手点攻击【同一个函数】✓）

③ 目标死了 / 跑远了（> 追击上限） → 丢掉目标，回 ①

④ 顺手做的事（可关）：
     · 自动捡脚下的掉落物
     · 血量低于 X% → 自动触发"回安全区"（就是我们刚做的那个传送 ✓ 读条 6 秒 ✓）
```

★★ **关键：不新写一套移动/攻击 ✗**
   全部复用现有的 `move` 发送 + `atk` 发送 ✓
   → 手感、音效、动画、伤害全都和手动一模一样 ✓
   → 也不会有"自动战斗打得比人快"这种问题 ✓

## 4. 防止变傻：几条保险

| 情况 | 处理 |
|---|---|
| 卡在墙边/树边（走了 1.5 秒几乎没动） | 判定卡住 → 侧向绕一下（左右随机 ✓），再卡就放弃这个目标 6 秒 |
| 目标在安全区里 | 不打（服务器也会拦 ✓ 但客户端先跳过更干净 ✓） |
| 追出去太远 | 超过【离家距离】上限 → 丢掉目标，走回来 |
| 自己被围住了 | 照常打（不特殊处理 ✓ 简单优先 ✓） |
| 玩家死了 | 立刻停（不能自动复活 ✗ 复活要点按钮 ✓） |
| 手动操作了 | ★ 自动【暂停 3 秒】✗ 然后恢复 ✓（不是直接关掉 ✓ 免得你想接管一下结果被关掉了 ✓） |
| 传送读条中 | 暂停自动（读条被打断就白读了 ✓ 站着别动更稳 ✓） |

## 11. ★ 打带跑（用户追加要求：别站撸，会死）

> 用户原话："可以做打一下拉开，再回去打吗，躲避僵尸的攻击，不然一直站撸容易死"

### 11.1 先说结论：**这个游戏本来就能躲** ✓（查过服务器代码了）

```
① 僵尸咬人是【两段式】：先蓄力 windup_of(kind) = 0.45 秒 → 才咬
   而 server/world.py 第 1021 行明确写着：
       m.windT = 0.0   # ★ 走开了就取消蓄力（重新贴身要重新起手 ✓）
   → 蓄力期间你退出它的攻击距离，这一口直接作废 ✓✓ 不是白躲 ✓

② 速度差很大（这是能不能风筝的前提）
   僵尸：mob_spd(L) = min(1.2 + 0.004L, 2.6)   → 30 级约 1.32，封顶 2.6
   玩家：明显更快（手动拉摇杆就能甩开僵尸 ✓）
   → 想拉开随时能拉开 ✓ 它追不上 ✓

③ 距离关系
   玩家 ATK_RANGE = 2.4 米
   僵尸要贴身才咬得到（同样按 2.4 判定）
   → 存在一个"我够得着、它够不着"的窗口（约 2.4 ~ 3.2 米）✓
     在这个窗口里打它，它只能一直追、一直够不着 ✓
```

### 11.2 三种打法（做成一个下拉选择）

| 模式 | 怎么打 | 优点 | 缺点 |
|---|---|---|---|
| **站撸** | 贴上去一直砍 | 打得最快 | 一直挨打 ✗ 血掉得快 |
| **打带跑**（推荐）| 砍一刀 → 退到 3.2 米外 → 它追进来 → 再砍 | ★ 挨打极少 ✓ 挂机稳 | 慢 30~40% |
| **绕圈** | 贴着它的攻击距离边缘转圈打 | 不往后退（不会拉更多怪 ✓）| 需要空旷场地 |

★ 默认用【打带跑】✓ 理由：挂机最怕的是死 ✗ 而不是慢 ✓
★ 但做成可切换 ✓ 想快点刷就切站撸 ✓

### 11.3 打带跑的节奏（具体怎么动）

```
① 进入攻击距离（≤ 射程×0.92）→ 停下 → 转向 → 挥一刀
② 挥完立刻【往后退】：朝反方向走 0.45 秒
     （0.45 秒 ≈ 僵尸的蓄力时间 ✗ 就是为了卡掉它这一口 ✓
       按玩家速度大约退出 2 米 ✓ 正好出它的攻击圈 ✓）
③ 退到位后【回头】继续挥（如果冷却好了）或等它追进来
④ 它追进来 → 重复 ①
★ 全程像"打一下跳一下"的节奏 ✓ 频率大概 1.2~1.6 秒一轮 ✓
```

### 11.4 什么时候【不】打带跑（防变傻）

```
· 周围僵尸 ≥ 3 只（都在 4 米内）→ 改站撸 ✗
    理由：退也退不出去 ✓ 一退反而拉更多 ✓ 不如原地打 ✓
· 目标在安全区边上 → 不追（照旧 ✓）
· 血量低于设定阈值 → 直接触发"回安全区"（不是继续跑位 ✓）
· 在墙角/窄道里 → 退无可退 → 改站撸 ✓
```

### 11.5 需要你再拍一个板

```
⑧ 默认用哪种打法？
   我建议【打带跑】✓（你说的痛点就是"容易死"✓ 这个最对症 ✓）
   备选：站撸（刷得快 ✓）· 绕圈（不会拉怪 ✓）

⑨ 要不要把"被围住就改站撸"的阈值做成可调？

## 12. ★ 死了怎么办（用户追问："会自己复活吗"）

### 12.1 先说现状（还没做自动战斗的时候）

```
死了 → 屏幕出现【复活】按钮 → 必须手点 ✓
★ 唯一的例外：刷新页面 = 复活 ✓
  （第 192 轮修的那个 bug 带来的副作用：登录时血量 <=0 一律按满血算 ✓
    所以"死着刷新"等于原地复活 ✓ 算是意外收获 ✓）
```

### 12.2 自动战斗 v1 【故意不做】无脑自动复活 ✗

```
理由：自动战斗 + 无脑自动复活 = 真正的永动机 ✗
      死了立刻站起来接着打 ✓ 挂机就没有任何代价了 ✓
```

### 12.3 ★ 但"挂机死了怎么办"是个真问题 —— 建议做【安全复活】

```
问题：服务器现在的复活是【原地满血站起来】✓
      如果是死在怪堆里 → 站起来又被咬死 → 又站 → 死亡循环 ✓✓
      （用户不在电脑前 ✗ 根本不知道 ✓）

建议做成一个选项（默认开 ✓）：
  死亡时：
    ① 自动点复活（满血 + 1.5 秒无敌 ✓ 服务器已有 ✓）
    ② ★ 紧接着自动发起"回安全区"传送（复用第 173 轮做的那套 ✓ 读条 6 秒）
    ③ 到安全区后【原地待着】✗ 不再自动出去打
       → 想继续挂机：自己点一下【自动】按钮 ✓

  ★ 防死亡循环保险（必须有 ✗ 不然就是无限送死 ✓）：
     10 秒内死第二次 → 直接关掉自动战斗 + 提示
     「你被反复击杀，自动战斗已关闭」
  ★ 传送读条会被攻击打断 ✓ 所以"安全复活"也不是 100% 保命 ✓
     但配合【低血自动回城】（提前跑 ✓）绝大多数情况死不了 ✓
```

### 12.4 三个选项给用户选

```
A. 做（推荐）：死了 → 复活 → 回安全区 → 停手 ✓
B. 不做：死了就躺着 ✗ 等你回来手点 ✓
C. 做，但去掉"回安全区"那步（原地复活接着打）
   ★ 不推荐 ✗ 这就是死亡循环 ✓ 唯一能用的场景是"周围怪已经清光了"✓
```
