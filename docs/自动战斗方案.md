## 1. 一句话说清

**自动战斗 = 客户端自己"假装有个玩家在操作"** ✓
它做的每一件事（往哪走、什么时候挥刀）都是一个真人能做出来的 ✓
所以**服务器一行都不用改** ✓

```
打开后：自动找最近的僵尸 → 走过去 → 到射程内就砍 → 捡东西 → 继续找下一只
关掉后：立刻停手，交回给你手动控制
```

---

## 2. ★ 为什么放在客户端做（这条要先说清楚）

```
这个项目的规矩：
  · 位置：客户端是权威的 ✓（服务器采信客户端报的坐标）
  · 伤害/掉落/死亡：服务器是权威的 ✓（服务器自己算扇形命中）

如果放在服务器端做 ✗：
  服务器一边推着你走 ✓ 客户端一边报自己的位置 ✗ → 两边打架 ✓
  （这个架构下服务器没有"移动玩家"的能力 ✓ 硬做会很难看 ✓）

放在客户端做 ✓：
  它只做两件事：改自己的位置（本来就归客户端 ✓）+ 发 atk 意图（和真人一样 ✓）
  → 服务器完全看不出来差别 ✓ 也不需要任何新协议 ✓
★ 代价（如实说）：客户端能做出来的事，理论上外挂也能做 ✗
  但试玩阶段无所谓 ✓ 而且这套本来也没防外挂 ✓
```

---

## 3. 它每一帧做什么（核心逻辑）

```
① 没目标 → 在【自身 R 米内】找最近的活僵尸
     · 跳过已死的（hp<=0 的还在播倒地动画 ✓ 不算）
     · 跳过【安全区内】的（安全区里僵尸进不来 ✓ 但边界上可能有 ✓ 一起跳过更稳）
     · 池子里没有 → 原地待机（不乱跑 ✓）

② 有目标 → 判断距离
     · 距离 > 射程×0.85 → 朝它走（和摇杆走的是【同一套移动代码】✓ 速度一样 ✓）
     · 距离 ≤ 射程×0.85 → 停下，转向它，冷却好了就挥刀（和手点攻击【同一个函数】✓）

③ 目标死了 / 跑远了（> 追击上限） → 丢掉目标，回 ①

④ 顺手做的事（可关）：
     · 自动捡脚下的掉落物
     · 血量低于 X% → 自动触发"回安全区"（就是我们刚做的那个传送 ✓ 读条 6 秒 ✓）
```

★★ **关键：不新写一套移动/攻击 ✗**
   全部复用现有的 `move` 发送 + `atk` 发送 ✓
   → 手感、音效、动画、伤害全都和手动一模一样 ✓
   → 也不会有"自动战斗打得比人快"这种问题 ✓

## 4. 防止变傻：几条保险

| 情况 | 处理 |
|---|---|
| 卡在墙边/树边（走了 1.5 秒几乎没动） | 判定卡住 → 侧向绕一下（左右随机 ✓），再卡就放弃这个目标 6 秒 |
| 目标在安全区里 | 不打（服务器也会拦 ✓ 但客户端先跳过更干净 ✓） |
| 追出去太远 | 超过【离家距离】上限 → 丢掉目标，走回来 |
| 自己被围住了 | 照常打（不特殊处理 ✓ 简单优先 ✓） |
| 玩家死了 | 立刻停（不能自动复活 ✗ 复活要点按钮 ✓） |
| 手动操作了 | ★ 自动【暂停 3 秒】✗ 然后恢复 ✓（不是直接关掉 ✓ 免得你想接管一下结果被关掉了 ✓） |
| 传送读条中 | 暂停自动（读条被打断就白读了 ✓ 站着别动更稳 ✓） |

## 5. 界面（三处）

```
① 常驻按钮（底部中间，传送按钮【左边】）
      〔自动〕 ← 关：深灰描边 / 开：绿框 + 呼吸效果
      点了立刻生效 ✓ 状态记在本地设置里（下次打开还是上次的样子 ✓）

② 状态提示（开的时候显示在按钮上方一行小字）
      "自动战斗：僵尸 Lv.12 · 8.3m"     ← 一眼看出它在干嘛 ✓（排查也方便 ✓）
      没目标时："自动战斗：附近没有僵尸"

③ 菜单 → 操作 里的设置项
      ☑ 自动战斗（和按钮同步 ✓）
      ☑ 自动捡东西
      目标优先级： [正在打我的 ▾]  最近 / 血最少 / 正在打我的
      追击距离：   [30 米 ▾]       15 / 30 / 50
      低血回城：   [30% ▾]         关闭 / 20% / 30% / 50%
```

## 7. 怎么验收（做完我会逐条测）

```
□ 开自动 → 10 秒内必须能打到一只僵尸（headless 测试 ✓ 用固定种子僵尸）
□ 玩家确实在移动（坐标变化 ✓ 速度不超过手动上限 ✓）
□ 关掉 → 立刻停手停脚 ✓
□ 手动拉摇杆 → 自动暂停 3 秒 → 松开后恢复 ✓
□ 卡墙测试：把玩家放在墙角 + 目标在墙后 → 不能无限撞墙（6 秒内放弃 ✓）
□ 低血回城：把血调到 25% → 到阈值 → 自动发起传送 ✓
□ 安全区：站在安全区里开自动 → 不会挥刀（服务器也拦 ✓ 双保险 ✓）
□ 死亡：被咬死 → 自动立刻停止 ✓ 不会自动复活 ✓
□ 挂机 5 分钟不掉线、不内存泄漏（飘字池/目标引用要清干净 ✓）
```

## 8. ★ 需要你拍板的 7 件事

```
① 目标优先级默认用哪个？
   我建议【正在打我的 > 最近的】✓（先解决眼前的威胁 ✓ 更像个正常人 ✓）
   备选：最近 / 血最少（收残血）

② 追击距离默认多少？
   我建议 30 米 ✓（太远会追得满地图跑 ✓ 太近又老是没怪打 ✓）

③ 低血自动回城要不要？
   我建议【要，默认 30%】✓（配合我们刚做的传送读条 ✓ 挂机不容易死 ✓）
   ★ 但传送要读条 6 秒 + 受伤会打断 ✓ 所以它不是无敌 ✓（低血了还是可能被打死 ✓）

④ 自动捡东西要不要？
   我建议要 ✓（不然挂机一会儿地上就一堆东西 ✓ 而且捡东西本来就走过去就行 ✓）

⑤ 手动操作时怎么处理？
   我建议【暂停 3 秒再恢复】✓ 不是直接关掉 ✓
   （你想接管几秒钟打一下，然后它接着自动 ✓）

⑥ 要不要"自动反击其他玩家"？
   我建议 v1【不做】✗ 只打僵尸 ✓
   理由：PVP 是自愿的 ✓ 自动打人容易结仇 ✓ 而且魔气系统会因此变得很奇怪 ✓
   如果你要，我加一个【默认关闭】的开关 ✓

⑦ 挂机会不会影响平衡？
   ★ 这个我得提醒你：
     · 挂机 = 经验/掉落/魔气都会自动涨 ✓（魔气只有杀玩家才涨 ✓ 所以没事 ✓）
     · 但【挂机刷怪升级】会让等级膨胀 ✓ 几个人玩无所谓 ✓ 人多了要考虑 ✓
     · 我的建议：先做 ✓ 试玩阶段本来就是图方便 ✓ 以后要限制再说 ✓
```
