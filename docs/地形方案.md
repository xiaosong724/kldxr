## 2. 高度

### 2.1 数据结构

```
每格存三个值：
   h    高度（整数层）✗ 0 = 地面 ✗ 负数 = 坑（最深 −1）✓
   mat  材质（草/土/石/砖/木/冰/泥）
   sl   斜坡方向（没有斜坡就是 0 ✗ 见 §2.5）✓

高度范围：−1 ~ 5
   ★ 为什么最高只到 5：再高会挡住视野 ✗ 相机俯角 58° 看不到墙后面 ✓
     而且人只有 2 格高 ✗ 5 层 = 2.5 个人 ✓ 已经很有气势 ✓
```

### 2.2 一格多大

```
推荐：一格 = 0.62 世界单位（沿用现在的 G.TS ✓）
   人物碰撞箱 0.6 × 0.5（完全不变 ✓）
   人物高 2 格 = 1.24
   → 现有所有数值都不用改 ✓ 风险最小 ✓

（备选：1.24 ✗ 更"厚"✗ 但要把碰撞箱一起改 ✓ 不推荐第一版就动 ✓）
```

### 2.3 高度怎么生成

```
h = 0
  + 低频噪声 A（波长 ~14 格）→ 0 ~ 2 层     ← 大起伏、缓坡
  + 低频噪声 B（波长 ~5 格） → 0 ~ 1 层     ← 小台阶
  + 山：见 §2.6（按到山心的距离算）

★ 只用【格子坐标 + 世界种子】算 ✗ 不依赖任何别的状态 ✓
★ 安全区（±15 单位）强制拍平成 0 ✗ 堡垒里不能有坑 ✓
```

### 2.4 渲染

```
每个区块（32×32 格）合并成一个 BufferGeometry：
  · 顶面：每格 1 个四边形
  · 侧面：只画【比邻居高】的那部分 ✗ 被挡住的完全不生成 ✓
    平地上 0 个侧面 ✓ 只有台地边缘才有 ✓
  · 底面：不画

估算：1024 格 → 顶面 2048 三角形 + 侧面约 600 → 一个区块 ~2600 三角形
     视野内约 12 个区块 → 3 万三角形 ✓ 手机上没问题 ✓（和现在画树差不多）
```

### 2.5 斜坡（不用跳就能走上去）

```
斜坡也是【一格】✗ 只是顶面是斜面 ✓

  数据：h（低端高度）+ sl（升高方向：东/南/西/北）
  视觉：一格宽的斜板，从 h 抬到 h+1
  走进去：人物 Y 在这一格内线性插值 ✓ 不减速 ✓ 不用跳 ✓

★ 为什么要斜坡：
  光有台阶的话 ✗ 上山要一格一格跳 ✓ 很烦 ✓
  斜坡是"能走的路"✗ 台阶是"要跳的坎" ✓ 两种都要有 ✓

★ 生成规则：山体外圈【自动铺一圈斜坡】✗ 保证每座山都爬得上去 ✓
  （否则会生成爬不上去的孤峰 ✗ 玩家会很烦 ✓）
```

### 2.6 小山

```
山的形状 = 按【到山心的距离】算高度：

  h = clamp(round(HILL_H - dist × slope), 0, HILL_H)
  HILL_H 一般 3 ✗ slope ≈ 1.1 ✗ 半径 3~5 格 ✓

  → 自然形成"一圈一圈矮下去"的锥形 ✓
  → 山顶放石头（能拆、能居高临下 ✓）
  → 山脚留 1~2 格平地（好摆阵 ✓）
  → 外圈铺斜坡（§2.5）✓

★ 反例（不要这样做）：
  手排格子 → 会变成"一堆盒子"✗ 完全不像山 ✓
  （我第一版示意图就是这么画的 ✗ 改了三版才像一个山包 ✓）
```

## 3. 人物与碰撞

### 3.1 占位

```
人物占两格：脚下那格（实心）+ 头上那格（必须是空气）

   ┌───┐  ← 头顶格：必须空
   │ 人│
   ├───┤  ← 脚底格：实心
   │地面│
   └───┘

★ 所以 1 格高的洞钻不进去 ✓（人 2 格高 ✓）这是对的 ✓
```

### 3.2 上下坡判定

```
落差 = 目标格高度 − 当前格高度

  落差 ≤ 0    ：走下去（掉不掉血看 §4）
  落差 = +1   ：自动迈上去（台阶 ✓ 不减速 ✓）
  落差 = +2   ：★ 跳不上去（只能跳 1 格 ✗）→ 找斜坡 / 破坏
  落差 ≥ +3   ：墙 ✗ 跳也上不去 ✓
  斜坡格      ：无视落差 ✗ 直接走 ✓（这是斜坡的作用 ✓）
```

### 3.3 碰撞顺序（每次移动）

```
1. 算目标位置 → 落在哪一格
2. 那一格 + 头顶那格有没有【实心物件】（树 / 房子）
3. 高度落差能不能过（§3.2）
4. 都过了才真的移动
```

### 3.4 跳跃（新增）

```
按钮：放在【攻击键左下角】✗ 直径约攻击键的 60% ✓ 拇指不用挪 ✓

参数（初版）：
  跳跃高度   1 格（= 1.0 × 层高）
  滞空时间   0.35 秒
  起跳速度   4.2（水平跑速 4.4 ✗ 跳不会变快 ✓）
  冷却       0.15 秒（不能连跳刷位移）
  空中控制   可以转向 ✗ 但不能加速 ✓

能干什么：
  ✓ 跳上 1 格高的台子（走路也行 ✗ 跳更快）
  ✓ 跨过 1 格宽的坑（2 格跳不过 ✓）
  ✓ 从高处跳下去（自己选 ✗ 但会掉血 ✓）

跳不上去：
  ✗ 2 格以上的台子
  ✗ 头顶有东西（洞里跳不起来）
  ✗ 站在冰上：起跳会滑开（见 §6.1）

★ 跳跃只能 +1 格 ✗ 所以"上不去的台子"是常态 ✓
  这就是【斜坡】和【破坏系统】存在的理由 ✓ 三个系统是连在一起的 ✓
```

## 4. 掉落

```
落地时算一次：落差 = 起跳格高度 − 落点格高度

  落差 ≤ 2   ：不掉血
  落差 ≥ 3   ：伤害 = (落差 − 2) × 8% 最大生命 ✗ 上限 60%

举例（最大生命 200）：
  落差 3 → 8%  = 16 血
  落差 4 → 16% = 32 血
  落差 5 → 24% = 48 血
  落差 8+ → 60% 封顶 = 120 血

★ 落点下面是水：不掉血 ✗ 但移速变慢（沼泽 ✓）
★ 落点被占（墙/树）：人卡边上 ✗ 不算掉落 ✓（挪到最近能站的地方 ✓）
★ 从斜坡走下来【不算掉落】✗ 高度是连续的 ✓
```

**为什么按百分比**：

```
按固定值的话 ✗ 低级号摔死、高级号无感 ✓
按百分比：8% × (落差−2) ✗ 谁摔都疼得有道理 ✓
上限 60%：从再高跳下来也留 40% ✗ 不会变成"摔死游戏" ✓
```

★ **判定放服务端** ✗ 客户端只做表现 ✓（否则改客户端就能免伤）

## 5. 破坏

### 5.1 打谁

```
挥刀时【先判地形】✗ 顺序很重要 ✓

1. 前方扇形内（ATK_ARC 60° ✗ ATK_RANGE 2.4）有没有可破坏的格子/物件
2. 有 → 打它（扣耐久 ✗ 不掉怪血 ✓）
3. 没有 → 照旧打怪

★ 不先判地形的话：站在墙前打僵尸 ✗ 墙永远拆不掉 ✓
★ 多人打同一格：耐久【共享】✗ 越快拆完 ✓
```

### 5.2 材质表

| 材质 | 打几下碎 | 出现在哪 | 碎了掉什么 |
|---|---|---|---|
| 草丛 / 泥土 | **1** | 地面层 | 什么都不掉（变坑） |
| 木头 | **2** | 树、枯树、木栅栏、木墙 | 木头 ×1~2 |
| 冰 | **2** | 冰原 | 碎冰（只做视觉，很快化掉） |
| 砖 | **4** | 房子墙、城区废墟 | 碎砖 ×1 |
| 石头 | **6** | 山顶、岩石、石台 | 石块 ×1（低概率） |
| 混凝土 | **8** | 军事区（以后） | 铁屑（以后） |

```
★ 为什么"草 1 下、石 6 下"：
  草土是【软化地形】✗ 一下掀掉 → 挖战壕、开近路 ✓
  石头是【战略资源】✗ 6 下 = "想拆山得花时间" ✓
  → 玩家自然形成"绕路 vs 挖穿"的选择 ✓ 这就是玩法 ✓
```

### 5.3 破坏后的样子

```
· 地面层打碎 → 变成坑（h 降到 −1）✗ 能站进去 ✓
  ★ 坑不叠加：挖到 −1 就到底（再挖变石头 ✓）

· 台地/墙打碎 → 那一格消失 ✗ 上面的格子【塌一层】✓
  ★ 只塌一格 ✗ 不连锁（免得半座山塌掉 ✓）

· 树被打碎 → 整棵消失 ✗ 掉 1~2 木材 ✓
· 房子墙打碎 → 墙消失 ✗ 房子不塌（简化 ✓）
```

### 5.4 现有的树和建筑

```
这两类现在是【独立 mesh】✗ 已经在 solids[] 里 ✓

改动：
  ① 给每个物件加 hp（按材质查表）
  ② 打到 0 → 从 solids[] 删掉 + 播碎裂 + 销毁 mesh
  ③ 服务端记住"这棵没了"（存库 §8）
```

### 5.5 破坏状态存库

```
新表 terrain_damage：
   (x, z, h, mat, hp)   ← 只存【和生成值不同】的格子 ✓

★ 平时这张表是【空的】✗ 只有被打过的格子才有一行 ✓
  → 不会让库暴涨 ✓
★ 掉落/重登：先按种子算出地形 ✗ 再把这张表的覆写叠上去 ✓
```

### 5.6 破坏动画（逐帧怎么做）

**四层，按"每刀都做 / 只在碎时做"分**：

```
① 命中抖动          【每一刀】
   · 模型沿【受击方向】位移 2px ✗ 0.08 秒回弹 ✓
   · 实现：改 mesh.position（或顶点 shader 里的 uniform 偏移）
   · 作用：立刻有"打到东西"的反馈 ✓

② 碎屑粒子          【每一刀】
   · 每次命中掉 3~5 个小方块（按材质颜色）✗ 抛出去 0.5 秒 ✓
   · 实现：对象池 32 个（复用 ✗ 不新建 ✓）
   · 音效：木头闷 / 石头脆 / 冰亮

③ 裂纹贴图          【过阈值时换】
   · 三张图：完好 / 裂一道 / 裂一片
   · 血量到 1/3、2/3 各换一次 ✓
   · 实现：同一材质共用 3 张图 ✗ 换纹理 offset / 或两层贴图叠 ✓
   · 作用：让玩家【看得出还要几刀】✓（没有裂纹就不知道什么时候碎 ✓）

④ 碎裂 + 尘烟       【只在最后一下】
   · 方块炸成 8~12 块 ✗ 抛物线飞散 ✗ 落地淡出 ✓
   · 一团尘烟（billboard 面片扩散 ✓）
   · 原地留一块"碎石地"纹理
   · 实现：InstancedMesh（一次 draw call ✓ 60 个实例封顶 ✓）
```

**耗时目标（手机）**：

```
普通一刀  ~3ms（抖动 + 3 个粒子）
碎的那一刀 ~8ms（10 块 + 尘烟）
→ 一帧 16ms 预算里完全够 ✓
```

**三条铁律**：

```
★ 命中抖动和碎屑必须【同帧】出现 ✗ 有延迟就没有打击感了 ✓
★ 裂纹三张图就够 ✗ 不用做动画 ✓ 换图那一瞬玩家会自己"听到"进度 ✓
★ 碎块落地【马上消失】✗ 留在地上会越积越多 ✓ 只留一块碎石地纹理 ✓
```

## 6. 地貌

| 地貌 | 视觉 | 手感 | 僵尸 |
|---|---|---|---|
| **荒野**（默认） | 草 + 土 + 石头小山 | 正常 | 正常 |
| **冰原** | 浅蓝白，反光 | 移速 **×1.35** ✗ 加减速都慢（惯性）✗ 转身也慢 | 同样打滑 ✗ 会滑过头 |
| **沼泽** | 深绿 + 水面到脚踝 + 涟漪 | 移速 **×0.6** ✗ 有踩水声 | 移速 ×0.8 |
| **城区废墟** | 砖地 + 断墙 + 废车 | 正常 | 正常，从缺口涌进来 |
| **军事区**（以后） | 混凝土 + 铁网 | 正常 | 更强 |

### 6.1 冰面（刹不住车）

```
普通地面：松开方向键 → 立刻停（现在就是这样 ✓）
冰面：速度每帧 ×0.92 衰减 ✗ 松开还会滑 ~0.6 格 ✓
      转向：朝向每秒最多转 240°（普通地面是瞬间 ✓）
      → 急转弯会"甩尾"✓ 很爽 ✗ 也很危险 ✓

★ 只改"摩擦"✗ 不改"最大速度"✓
  改最大速度 → 冰面跑得飞快 ✗ 变成竞速图 ✓
  改摩擦 → 起速一样 ✗ 但停不下来 ✓ 这才是"冰"✓
★ 在冰上起跳会滑开（跳跃不锁方向 ✗ 但起跳瞬间保留惯性 ✓）
```

### 6.2 沼泽（慢 + 有积水）

```
速度 ×0.6
水面：那一格顶面抬到"脚踝高度"（0.3 格）✗ 半透明 + 轻微波动 ✓
踩上去：溅一圈涟漪（0.4 秒消失 ✓）+ 踩水声
视觉：水是【贴在地面上的一层】✗ 不是一池子水 ✓
```

### 6.3 分布

```
按【区块】整片生成（32×32 格一个区块）✗ 不零碎 ✓
  < 60 单位      → 荒野（新手区）
  更远           → 噪声决定冰原 / 沼泽 / 城区
★ 冰原和沼泽【整片都是】✗ 中间不夹草地 ✓ 好认 ✓

高度和地貌【独立但相关】：
  冰原 → 强制低平（h ≤ 1）
  沼泽 → 强制低平（h = 0，全是水）
  城区 → 允许 1~2 层（楼基）
  荒野 → 允许 0~5 层（有小山 ✓）
```

## 7. 怎么做才好看（用户特别问的）

### 7.1 先说结论

```
这个游戏是【近似俯视】的 3/4 视角 ✗ 高度差不会自己"跳出来"✓
必须靠【明暗】把高度读出来 ✓

  立体感 = 侧面明暗（60%）+ 接触阴影（30%）+ 边缘细节（10%）
  ✗ 不是靠"建模精细"✓（手机上也做不到 ✓）
```

### 7.2 四档对比（`terrain-look.png`）

```
A · 纯色方块        ← 现在的地面就是这样 ✗ 平的
B · 侧面明暗        ← 每层固定亮度 ✗ 能看出高度了 ✓（只要一行代码）
C · 接触阴影+投影   ← ★ 立体感主要来自这一步
D · 边缘高光+草边   ← 最终想要的效果
```

### 7.3 七条技法（按性价比排序）

| # | 技法 | 做法 | 成本 |
|---|---|---|---|
| 1 | 侧面每层固定亮度 | h=0 的侧面 0.72 ✗ 高的亮/矮的暗要**统一**（否则同一层一半亮一半暗） | 1 行代码 |
| 2 | **接触阴影（假 AO）** | 侧面靠近底面那几行压暗 ✗ 顶面靠边一圈也压暗 ✓ **收益最大** | 顶点色/shader |
| 3 | 高处投影到低处 | 比邻居高的格子在低处投一个软菱形阴影 ✗ 人在山上时影子落在山下 ✓ | 一次 draw call |
| 4 | 顶面上沿高光 | 顶面上两条边提亮 ✗ 像被天光照到 ✓ 一下"凸"起来 | 顶点色 |
| 5 | 边缘长草/碎石 | 台地边缘不要是直边 ✗ 撒一圈小草精灵 ✓ 遮住方块感 | 实例化 sprite |
| 6 | 每层高度不一致 | 全一样高会像棋盘 ✗ 顶面 ±2px 随机偏移 ✓（只改视觉 ✗ 不改碰撞） | 顶点抖动 |
| 7 | 远景雾 | 远处淡出到背景色 ✓ 盖住区块边界 ✓ 也省性能 | 已有 fog |

## 9. 分阶段实施

> 每一阶段都能【单独上线】✗ 不用等全部做完 ✓

### P0 · 高度（最重要，其他都建在它上面）

```
□ server/terrain.py（新文件）：高度 + 材质 + 斜坡 的纯函数（无状态、可离线测）
□ 客户端 buildChunk 改成按 terrain.py 同样的规则算
□ 地面几何：平面 → 合并方块几何（只画露出的面）
□ 侧面明暗 + 接触阴影（§7.3 第 1、2 条）★ 这两条决定"好不好看"
□ 人物 Y 跟随地形（含斜坡插值）
□ 落差判定（走不过 2 格墙）+ 掉落伤害
□ 跳跃按钮 + 0.35 秒滞空
□ 交叉验证测试：客户端 vs 服务端逐格比高度（照抄现有 dump_props 那套）
```

### P1 · 破坏

```
□ 材质表（硬度 + 掉落）
□ 挥刀时先判地形
□ 裂纹三段 + 命中抖动 + 碎屑粒子
□ 碎裂动画 + 碎块对象池（InstancedMesh）
□ 树 / 房子接入破坏
□ 破坏状态存库（terrain_damage 表）
```

### P2 · 地貌手感

```
□ 冰面惯性（改摩擦 ✗ 不改最大速度）
□ 沼泽减速 + 水面 + 涟漪

```

```
□ 掉落伤害移到服务端判

```

## 10. 风险

| 风险 | 后果 | 应对 |
|---|---|---|
| 客户端/服务端高度算法不一致 | 僵尸穿墙、玩家悬空 | **第一件事就写交叉验证测试** ✗ 改任何一边都跑 ✓ |
| 几何量太大 | 手机掉帧 | 只画露出的面 + 合并几何 + 区块剔除 ✓ P0 就压测 |
| 破坏状态存库太大 | 库暴涨 | 只存和生成值不同的格子 ✓ 平时是空的 |
| 老存档没有高度 | 全部变平地 | 高度是【算出来的】✗ 不存 ✓ 所以老存档自动就有地形 ✓ |
| 斜坡插值不连续 | 人物在坡上抖动 | Y 由【格子内进度】线性插值 ✗ 不要用速度积分 ✓ |
